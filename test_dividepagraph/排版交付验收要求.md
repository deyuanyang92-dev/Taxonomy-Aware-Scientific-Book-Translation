# 排版交付验收要求（用户 2026-11-23 定，所有模型适用）

## 0. 用户要什么
一个完成的、可直接使用的排版系统和成品，不是实验、不是对比、不是选择题。用户没有时间对接，已经做过大量排版工作和测试。
功能目标：从同一份对齐 JSON 产出 HTML、PDF、Word；改一个标题很快；改一级标题样式，同级所有标题立刻跟着变；含图片排版。

## 1. 开工前必做（不做就是违规）
1. 读 docs/booklayout-standard.md、docs/booklayout.md、docs/taxonomic_typography.md、booklayout/stylecheck.py、booklayout/acceptance.py。
2. 以用户已确认的样板为下限：Imajima 2007 p1-12 v8（/mnt/p/翻译-译作/日本-imajima/试译/baseline/imajima_p1-12_baseline.{docx,pdf}，2026-11-21 用户确认）。检索表以 key-align 流程为准。
3. 查历次排版交付和用户批评：yanjie/deliver/、各 交付_* 目录、git log 中 booklayout 提交、yzz-mistakes 的 MISTAKES.md（A1、E2、H7、H8）、memory。不重复已犯的错。
4. 在现有 booklayout 上扩展，不新建平行系统。不手改 HTML 或 docx。

## 2. 成品必须包含（缺一项不得交）
| 项 | 要求 |
|---|---|
| 内容 | 正文、标题各级、图、图注、检索表、种条目、参考文献、索引、页眉页脚、页码、目录 |
| 图片 | 原书插图按页位置嵌入，图与图注配对，不溢出版心，不丢图，分辨率不低于原书；图版页与普通图分别处理 |
| 样式联动 | 样式集中在 profile；DOCX 使用真正的命名样式（Heading 1/2/3 等）；改 h1/h2/h3 样式一次，全书同级标题同变；测试：改样式后 document.xml 不变、只 styles 变 |
| 三种输出 | DOCX、PDF、HTML 均由同一份对齐 JSON 与 profile 生成，内容一致（有断言） |
| 速度 | 改一个标题或一个标题级别样式后，预览刷新 ≤ 数秒；全书终稿仍可用两遍流程；耗时用同一台机器实测并记录，不凭估计 |
| 终稿 | DOCX 为交付物，PDF 由其转出；两遍排版保证目录与页码正确 |

## 3b. Google 样章对照（用户 2026-11-23 指定，设计明显好于旧实验）
参考：/mnt/p/翻译-译作/yanjie/google-neon/（34 页 PDF，Chromium 生成，Georgia 衬线；fauna_ib_rica.md 第 677–915 行是它的 Typst 组件模板）。
已核实可学（渲染第 3–6 页目检 + 读模板）：
| 项 | Google 做法 | 要求 |
|---|---|---|
| 页眉页脚 | 细线分隔；奇偶页不同（偶页页码在左、系列名右；奇页卷名左、页码右）；前 10 页不显示 | 成品具备同等页脚体系，中文版换成中文卷名 |
| 目录 | 表格式层级目录：亚科加粗、属缩进、页码右对齐加粗，上下细线 | 目录按阶元层级排，不是平铺 |
| 阶元标题 | 科/亚科/属/种各有组件：Familia 加斜体学名加命名人，作者年份行，同物异名行斜体小号 | 分类阶元标题层级样式集中在 profile，改一处同级全变 |
| 正文 | 10 pt 衬线，两端对齐，首行缩进，段间小间距，行距 0.62em | 与现有样板同级或更好 |
| 检索表 | key-item：编号右对齐、点线填充、目标加粗右对齐 | 沿用 key-align 流程，与 Google 并排对照 |
| 图版 | figure-plate：整页图加双栏斜体图注，不拆页 | 含真图，图注配对 |
| 流程 | 语义状态机解析 → 组件 → 一次编译；文称整书 2–5 秒（未确证） | 评估是否并入 booklayout，实测后才能引用该数字 |
Google 样章的缺陷（不要抄）：无插图；第 4 页属名粘连成一行（TrypanosyllisSyllisTrypanosyllis…）；正文里属名漏掉导致「géneros (, algunas」空缺；斜体学名靠手工，不是词表驱动；西语原文未翻译，不涉及中文排版与 CJK 字体。
验收：成品页与 Google 样章第 3–6 页并排，版面设计（字体、页眉页脚、目录、标题层级、行距）不得低于它，缺陷项必须没有。
