# 开源多语种分类学专著翻译与镜像排版软件 — 技术架构与开发规格书

> **文档用途**：可直接交付 AI 编程助手（如 Claude）或研发团队进行模块化实现的工程规格书（PRD + 系统架构 + 数据契约 + 算法规范 + 验收标准）。
>
> **项目定位**：面向科研与公益用途的开源多语种分类学专著（动物志 / 植物志 / 真菌志）翻译与重排工具。支持将**任意源语种**（西、法、德、日、俄等）专著高质量翻译为**标准英文（核心枢纽）**，并支持按需**选择性翻译为中文**，同时输出**与原书版式基本一致的高清镜像 PDF**。
>
> **基准实测样本**：*Fauna Ibérica, Vol. 21: Annelida, Polychaeta II: Syllidae*（Guillermo San Martín, 2003, CSIC, Madrid；实书 554 pp.，PDF 共 555 页）。

## 1. 核心设计哲学与算力预算策略

本项目是长期公益基础设施，设计第一原则是：**把成本从“反复消耗的 LLM Token”转移到“一次性沉淀、跨书复用的确定性资产（领域概念词表 + 参数化模板 + 传统 CV 算法 + 确定性 QC 门禁）”**。

### 1.1 四大架构铁律（给开发者的硬约束）

1. **分类学受控子语言优先（Lexicon-First）**：物种形态描述绝不是普通散文，而是极简电报体（无变位动词、高频术语与句型高度封闭）。软件必须先挖掘并锁定术语词表与句型模板，把 85% 的翻译任务降维成“词表约束下的轻量化语序粘合”。
2. **英语中心枢纽 + 按需译中（English Hub $\to$ Selective ZH）**：所有非英语专著统一先转化为标准学术英文（`en_final`），再根据用户指定的范围（如仅检索表、科总论或特定属种）从标准英文映射并精修为中文（`zh_final`），避免小语种直译中文失真，同时避免 $N^2$ 词表维护爆炸。
3. **图像与版面处理绝对禁止依赖高价视觉大模型**：针对 19–20 世纪老文献低质扫描件与 MRC 双层压缩 PDF，**98% 的图版隔离由本地纯 CV 算法（`PyMuPDF` + `OpenCV`）零成本完成**，最后 1%–2% 极端破损页由本地单文件 HTML 微工具人工 1 分钟拖框兜底，严禁批量向 Sonnet 发送整页大图。
4. **单一事实源与断点续传（Single Source of Truth）**：全流程围绕结构化中间层 `book_ir.json` 与本地 SQLite 句级缓存运转；修改术语、修正原书错印、切换中英模板均通过本地 `Patch` 引擎 3 秒重排，**0 额外 Token 消耗**。

### 1.2 算力分层分工表（DeepSeek Flash 夜间主力 + Claude Sonnet 攻坚）

| 流水线任务 | 指定执行引擎 | 负责范围与占比 | 现金成本定位 |
| :--- | :--- | :--- | :--- |
| **PDF 体检 / MRC 合层 / 老扫描去污 / 图版精准隔离** | 纯本地 Python (`PyMuPDF` + `OpenCV` + 轻量开源 OCR) | 100% 页面图像预处理、98% 图版自动提取与双通道画质重生 | **$0** |
| **极端破损页图框修正** | 本地静态网页 `review_plates.html` | 算法告警的最后 1%–2% 烂页（人工拖框导出 `manual_overrides.json`） | **$0** |
| **零翻译免处理区** | 本地 Python 正则与模板引擎 | 参考文献、异名附录、索引、名录、原始文献引证行、固定模板句（占全书 $\approx 22\%$） | **$0** |
| **主力批量翻译 & 按需译中** | **DeepSeek Flash（夜间低价时段）** | ① 辅助生成高频未收录词候选；② 结合动态微词表执行 85% 形态描述 / 图注 / 分布 / 生物学的电报体语法粘合；③ 按需 `EN -> ZH`；④ QC 报错句初修 | **极低（几毛至 1–2 元/本）** |

## 2. 基准样本实测诊断与可行性实证（*Fauna Ibérica Vol. 21*）

开发阶段的测试集与边界规则均以本书实测结果为准（当前已核验：PDF p. 1–123 完整图文 + 书前完整目录；PDF p. 124–555 边界以书前目录为准）。

### 2.1 原书 PDF 技术陷阱与实测勘误表

| 核验维度 | 实测准确事实 | 必须写入软件的工程对策 |
| :--- | :--- | :--- |
| **页码偏移** | PDF p. 10–100 对应印刷 p. 11–101（$\text{印刷页码} = \text{PDF页码} + 1$）；PDF p. 5、9 为扫描页，p. 6、10 为对应文本页 | Stage 1 必须生成精确的 `page_manifest.json` 映射 `pdf_page <-> orig_page`，严禁混用 |
| **MRC 双层 + 对开复用** | 自 **PDF p. 101（印刷 p. 102）** 起切换为 MRC 双层无文本扫描（前景黑底白字掩码 + 背景线条/电镜图），且相邻两 PDF 页复用同一幅双页对开扫描底图（依靠 `CropBox` 裁切左右页） | **禁止调用 `fitz.get_images()` 拆底层子图**；必须按 PDF `CropBox` 以 300 DPI 整页合层渲染，既自动融合 MRC 图字（保住图内 `A–G` 与比例尺），又天然切分左右页且不重复 |
| **分类单元精确统计** | 据目录（PDF p. 6–7）与伊比利亚名录（印刷 p. 42–46）：全书共 **4 亚科、36 属、149 个唯一物种**（名录印出 150 行，*Sphaerosyllis parabulbosa* 在 p. 43 与 p. 44 重复列出；p. 47 正文作者误写 *Eusyllinae* 为 10 属，实为 13 属） | 质检不得轻信正文口头统计，必须以 `book_ir.json` 树节点实数为准，并具备名录去重告警能力 |
| **原书排印量纲错印** | 印刷 p. 49（宽 `140 mm`）、p. 99（宽 `132-155 mm`）、p. 110（端片 `24-25 mm / 16 mm`）、p. 119（端片 `35 mm / 18 mm`）在原版扫描图中即误将 $\mu\text{m}$ 印作 `mm` | 独立的“量纲与生物学常识校验门禁”自动检测 `width > length` 等异常，输出时保留原值并加 `[sic, likely µm]`，不篡改原著 |
| **OCR/MRC 真实残缺** | 印刷 p. 47（`Reproducción epigámica. amica.`）、p. 48（`Neopetitia ( . 49 )`）、p. 61（属名误识 `Paraeblersia`）、p. 96（原书漏填 `p. 000`）、p. 108（MRC 剥离丢字 `Fauve ... Day`、`San ... 84a)`）、p. 118（`micircular / tentacula`） | 结合名录/WoRMS 自动纠偏学名；MRC 页一律重做合层 OCR；检索表走 DAG 拓扑校验拦截残缺行 |
| **嵌入式 L 形与多栏图注** | 图版下方图注常为 2 栏（如 Fig. 44, 46, 48, 52, 53）或 3 栏（Fig. 50, 51），部分呈 L 形嵌入图版空档（Fig. 9, 12, 17, 18） | 禁止简单横切页面；必须做多栏图注水平合并 + 像素级非矩形擦字留图 |

### 2.2 受控子语言定量实证（为什么词表驱动可行性极高）

1. **零变位动词验证**：逐词解剖印刷 p. 49 *Neopetitia* 属征（119 词）：解剖专词 31.9% + 形态性状方位词 26.1% + 基础数词 5.9% + 小学 A1 级虚词/介词 36.1% + **复杂变位动词 0.0%**。紧随其后的 *Neopetitia amphophthalma* 完整物种描述（p. 49–51，12 个长句）中，10 句不含任何变位动词。
2. **跨属词汇封闭性**：仅用 p. 49 *Neopetitia* 1 个属（119 词）构建微型初始词表，直接匹配 50 页后形态迥异的 p. 99 *Miscellania* 属征（101 词），**直接覆盖率高达 81.2%（82/101 词）**，仅需新增 16 个高频术语，且全段同样 0 个变位动词。
3. **公式化句型复现**：如 `ojos dispuestos en trapecio [abierto]`、`a través de unos [X] segmentos, con unas [Y] filas musculares`、`más larga(s) que el prostomio más los palpos` 在 149 个物种中高度重复，适合参数化模板 0 Token 命中。

```text

├── 1. FrontMatter (p. 1–10): 封面/扉页、版权页、编委会、目录(ÍNDICE)、卷内扉页
```

## 3. 系统总体架构、目录结构与 CLI 接口

### 3.1 八阶段解耦流水线

```text
[原始 PDF]
   │
   ▼ Stage 1: preflight    (PDF 体检、CropBox 300DPI 合层渲染、对开去重、老扫描信号清洗)
   ▼ Stage 2: profile      (15 页 Sonnet 极简结构探针 -> 自动生成 book_profile.yaml)
   ▼ Stage 3: plates       (纯本地 CV 图版隔离：H_char 字高指纹 + RLSA + 图注锚定双重验证 -> 1-2% 告警出 review_plates.html)
   ▼ Stage 4: parse        (确定性状态机 0 Token 构建 book_ir.json + 名录反抽学名白名单 + 断词清洗与纠偏)
   ▼ Stage 5: mine-terms   (本地 N-gram 词频扫描 -> 对齐星型概念词表 -> 未收录高频词批量审核沉淀)
   ▼ Stage 6: translate    (哨兵掩码 -> 参数化模板 -> DeepSeek Flash 夜间电报粘合 / Sonnet 总论与检索表精译 -> SQLite 缓存)
   ▼ Stage 7: qc & patch   (5 道零 Token QC 门禁 -> TSV Delta-Only 差分修复 -> 全局术语热更新 Patch)
   ▼ Stage 8: build        (按需 --zh-scope 译中 -> Typst 秒级编译：英文镜像 PDF / 中文版 / 双语对照 / 特征 CSV)
```

### 3.3 标准 CLI 命令设计

```bash
ott preflight  <input.pdf> --book-id fauna_v21 --dpi 300
ott profile    --book-id fauna_v21 --model claude-sonnet
ott plates     --book-id fauna_v21 --apply-overrides manual_overrides.json
ott parse      --book-id fauna_v21 --profile profiles/fauna_iberica_v21.yaml
ott mine-terms --book-id fauna_v21 --top-k 500 --out pending_terms.tsv
ott translate  --book-id fauna_v21 --target en --worker deepseek-flash --hard claude-sonnet --batch-mode night
ott qc         --book-id fauna_v21 --auto-repair-tsv
ott translate  --book-id fauna_v21 --from en --target zh --zh-scope keys,family_intro,genus_diagnosis
ott patch      --book-id fauna_v21 --glossary ontology/03_taxon_polychaeta.tsv
ott build      --book-id fauna_v21 --template mirror_en --out output/fauna_v21_en.pdf
```

## 5. 纯算法老文献图版隔离引擎（$0 API Cost DIA/CV Pipeline）

针对 19–20 世纪低质扫描老文献（泛黄霉斑、书脊阴影、背面透字、歪斜）、MRC 双层分离、稀疏刚毛线描图与 L 形嵌套图注，**采用“反向擦字 + 图注锚定 + 形态学聚框 + 双重验证”替代脆弱的通用版面模型与高价视觉 LLM**。

### Step 1：强制 `CropBox` 合层渲染与老扫描信号去污
1. **合层渲染**：用 `PyMuPDF` 按每页 `page.cropbox` 渲染 300 DPI PNG，彻底解决 MRC 图字分离与对开页重复问题。
2. **投影方差纠偏（$\pm 0.1^\circ$）**：在 $[-4^\circ, +4^\circ]$ 内按粗细两级扫描，最大化水平像素投影轮廓方差（抗插图干扰远胜霍夫变换）。
3. **去书脊中缝黑影**：检测页面左右各 8% 边缘的列中位数灰度梯度，若出现单调变暗阴影，按列估计背景并做除法归一化拉白。
4. **CIE Lab 去黄底霉斑（Foxing）**：彩色老扫描件转至 CIE Lab 空间，利用色度通道（`a/b` 高饱和）掩码洗白棕褐色水渍与霉斑，保留低色度黑色油墨。
5. **双阈值滞后抑透字（Dual-Threshold Hysteresis）**：设定强墨迹阈值 $T_{\text{high}}$ 与弱墨迹阈值 $T_{\text{low}}$，仅保留与强墨迹连通的弱像素，整片滤除孤立浅灰背面透字，同时完好保护点画法阴影（stippling）。

### Step 2：零 ML 自适应字高指纹（$H_{\text{char}}$）与四类文本劈分
对整页执行 `cv2.connectedComponentsWithStats`，统计连通域高度直方图，尖锐主峰即为该页正文字高 $H_{\text{char}}$。随后仅挑选高度在 $[0.45 H_{\text{char}}, 1.8 H_{\text{char}}]$ 的连通域做 **RLSA（水平行程平滑，阈值 $1.5 H_{\text{char}}$）** 聚类文本行，并结合轻量 OCR 将页内墨迹劈分为 4 类：

| 类别 | 确定性识别规则 | 文本流处理 | 图像画布处理 |
| :--- | :--- | :--- | :--- |
| **`HEADER_FOOTER`** | 顶/底 7% 区域，匹配页码或书眉正则 | 仅存页码元数据 | **像素级涂白擦除** |
| **`BODY_TEXT`** | 宽度 $> 5 H_{\text{char}}$ 的标准正文连续行 | 送入 `book_ir.json` | **像素级涂白擦除** |
| **`CAPTION`** | 锚定 `^(Fig\.|Figs\.|Abb\.|Pl\.|Taf\.|Plate|Рис\.|图|図)\s*\d+` 并**水平向右扫描合并同 Y 带多栏斜体块** | 送入 `plate.caption` | **像素级非矩形涂白擦除（专治 L 形嵌入图注！）** |
| **`PROTECTED_LABEL`** | 孤立 1–2 个字母/数字（`A–N`, `1a`）或电镜参数（`Magn`, `Acc.V`, `WD`, `5 µm`, `1000x`） | **从文本流剔除** | **严禁擦除！完整保留在原图内** |

### Step 3：图注锚定 + 宏/微观双重验证 + 自适应形态学聚框
1. **宏观三方核对**：比对正文引用图号集 $S_{\text{ref}}$ 与页面图注集 $S_{\text{cap}}$。仅对命中图注页或整页图版页切图；若 $S_{\text{ref}} - S_{\text{cap}} \neq \emptyset$，立即定位相邻页告警复检。
2. **微观 ROI 锁框与像素聚框**：
   * 以合并后的 `CAPTION` 块为基准划定搜索区 ROI（多图同页按图注 Y 坐标自然分区）；
   * 在已执行**像素级擦字**的画布上，滤除面积 $< 0.05 H_{\text{char}}^2$ 且孤立的噪点，用与 $H_{\text{char}}$ 成比例的大核做形态学膨胀，把分散的细刚毛、足刺与 `A–G` 标号聚类为一个完整外接框 $B_{\text{ink}}$；
   * 若接入轻量开源版面框 $B_{\text{det}}$ 做双重校验：$\text{IoU} > 0.85$ 直接通过；若 $B_{\text{ink}}$ 明显大于 $B_{\text{det}}$（说明版面模型漏了边缘细刚毛），自动以 $B_{\text{ink}}$ 扩框兜住全图。
3. **双通道画质重生**：
   * **线描图（白底 $> 75\%$）**：采用闭运算估计纸面背景光照做除法归一化 + 轻度色阶拉伸（$>238$ 拉纯白无缝融入排版纸面），**严禁硬二值化**以免摧毁点画法阴影；
   * **电镜/照片（连续灰阶）**：保留完整灰阶，仅提纯子图间白缝。
4. **表格与整页老图版确定性分流**：
   * **表格（`TABLE`）**：正交长核 `(40, 1)` / `(1, 40)` 形态学开运算检出横竖线，或无框表文字块左边缘对齐列峰 $\ge 3$，且锚定 `Table/Tabla/Tab.` $\to$ 送表格结构化翻译通道，不切图；
   * **整页老图版（`FULL_PAGE_PLATE`）**：多词文本行 $< 6$ 且非文本墨迹占比 $> 12\%$ $\to$ 整页保留，并与对页 `Explanation of Plates` 配对。

### Step 4：二次残字质检与 $0 人工兜底闭环
* 对裁出的每张最终图版跑一次轻量 OCR 复检：若仍检出连续 $\ge 4$ 个非参数外语词（`CAPTION_LEAK`），或宽高比极端（$> 6:1$）、面积 $< 5\%$（`POS_MISMATCH`），则标记告警。
* 所有告警页（通常仅占全书 1%–2%）自动打包进单文件本地网页 `review_plates.html`（内置 Canvas 拖框，双击浏览器打开，无需后端服务），人工花 1 分钟拖准红/蓝框后点击导出 `manual_overrides.json`，重跑 `ott plates` 即达 100% 像素级精准。

## 6. 词表驱动极简省 Token 翻译引擎

### 6.1 六项硬核节流机制

1. **全书实体白名单 + 无损哨兵保护**：自动解析名录（p. 42–46）与异名附录（p. 531–548）+ 本地 WoRMS 缓存生成拉丁名保护表。翻译前将拉丁名、引文年份、图号 `(figs. 12A–C)`、数值单位替换为纯字母数字哨兵（如 `XTAX1X`, `XFIG1X`, `XNUM1X`），砍掉 20%–30% 无意义字符并杜绝实体畸变。
2. **本地 N-gram 词频挖掘（先建库、后翻译）**：在翻译正文前，对 `book_ir.json` 跑 1–4 gram 频次统计，与 `ontology/` 已有词表做差集，仅将未收录的 Top 300–500 高频形态词一次性批量生成英文候选表供人工快速锁定。
3. **动态微词表注入（Micro-Glossary）**：发送每批 20–30 个句子时，严禁把 800 词全表塞进 System Prompt！脚本只提取**当前批次实际命中的 8–15 个概念词条**附在请求中，单次输入 Token 减少 80%–90%。
4. **分级翻译路由**：
   * **Tier 0（0 Token）**：书末文献/附录/索引、名录、原始引证、模式种、命中 `02_telegraphic_templates.tsv` 的句型直接本地处理；
   * **Tier 1（DeepSeek Flash 夜间）**：形态描述、图注、分布、生物学，传入哨兵掩码原文 + 动态微词表，极简 Prompt 指令：“严格保留 `X...X` 哨兵与给定英文术语，调整语序与基础连词，输出标准英文分类学电报体”；
   * **Tier 2（DeepSeek Flash / Sonnet 差分精修）**：仅处理 QC 门禁捞出的异常句，采用**紧凑 TSV 线协议 + Delta-Only 输出**（输入 `ID\t文本`，指令“准确行直接忽略，仅输出需修改的 `ID\t修正译文`”，压缩 70%–85% 高价输出 Token）；
   * **Tier 3（Claude Sonnet 纯文本）**：仅 15 页探针、科总论、二分检索表与分类学专题讨论，开启 Prompt Caching 与异步 Batch 模式进一步降本。
5. **SQLite 句级永久缓存**：以 `(src_lang, target_lang, src_md5, hit_glossary_hash)` 为主键缓存，改排版或重跑 0 重复计费。
6. **按需选择性译中（`--zh-scope`）**：在 `en_final` 通过全部质检后，按 CLI 参数（如 `keys,family_intro,genus_diagnosis` 或指定属名列表）从标准英文 + `zh_std` 概念表调用 DeepSeek Flash 夜间轻量生成中文。

## 7. 五道确定性零 Token 质检门禁（Deterministic QC Gates）

高质量不靠全书堆最贵模型，而靠**严苛的本地自动化门禁精准捞错 + 顶层模型定点外科手术式修复**：

1. **门禁 1 — 实体与哨兵守恒（`ENTITY_LOST`）**：校验 `clean_src` 中所有 `XTAX/XFIG/XNUM` 哨兵在译文中 100% 等量存在且还原无损。
2. **门禁 2 — 概念术语强制合规（`TERM_MISMATCH`）**：若源句命中 `trépano` / `mango` / `artejo(blade)` 等概念，校验 `en_final` 必须包含对应 `en_std` 词根（拦截日常误译如 `drill` / `handle` / `joint`）。
3. **门禁 3 — 二分检索表 DAG 拓扑校验（`KEY_GRAPH_ERR`）**：将每个检索表建为有向无环图，0 Token 断言：① 每个编号严格 2 条对偶项；② 所有数字跳转目标真实存在且无环路；③ 所有终点分类单元均能在 `taxa_registry` 中命中；④ 对偶项无明显异常截断。
4. **门禁 4 — 量纲与生物学常识体检（`UNIT_ANOMALY`）**：校验 `body_width > body_length`、刚毛端片或足刺单位误作 `mm` 等逻辑冲突，自动追加 `[sic, likely µm]` 溯源注记并写入审计报告。
5. **门禁 5 — 残余源语言与断句检测（`RESIDUAL_SRC` / `OCR_BROKEN`）**：检测英文译文中是否残留源语言高频停用词（如西语 `con/pero/hacia/entre`，法语 `avec/chez`，德语 `und/mit`）或残缺孤词，命中即打标送入定向修复队列。

  * **验收标准**：样本集端到端译成标准学术英文；`artejo` 按上下文精确区分 `blade` 与 `article`；输出 `token_cost.json` 透明账单，验证批量微词表注入与 TSV Delta-Only 协议生效。

  * **验收标准**：自动产出 `qc_audit.md`；执行 `ott patch` 修改任一术语可在 5 秒内无 Token 重编译全书；支持 `--zh-scope keys,family_intro` 仅输出指定范围中文或双语对照版。

### 9.3 给 AI 开发者（Claude）的强制编码守则
1. **严格模块解耦**：每个 Stage 必须可作为独立 CLI 子命令运行，只通过 `workspace/<book_id>/` 下的 JSON/PNG/SQLite 交换数据，支持随时中断续跑。
2. **绝不硬编码单书逻辑**：除 `profiles/*.yaml` 和 `ontology/*.tsv` 外，`src/` 核心代码不得写死任何西班牙语关键词或《Fauna Ibérica》专属页码。
3. **优先确定性算法，审慎调用 LLM**：所有 LLM 调用必须经由统一的 `LLMClient` 封装，强制记录每次请求的 `stage, model, prompt_tokens, completion_tokens, cached_tokens, estimated_usd` 到 `token_cost.json`，并强制写入 SQLite 缓存。
4. **保留原文溯源性**：任何针对原书错印（如 `140 mm`）或 OCR 残缺的修复，不得直接覆写 `raw_ocr`，必须写入 `patches[]` 数组并在译文中以 `[sic, ...]` 规范标注。
