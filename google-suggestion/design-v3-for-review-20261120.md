## 1. 任务与约束

**任务**：今島実（Imajima）三卷日文多毛类志书，均为整页扫描 PDF（每页一张整页图，文字层 0 字符）：

| 卷 | 页数 |
|---|---|
| 2009（Polychaeta I） | 361 |
| 2001（II） | 406 |
| 2007（III） | 363 |

产出：英文版 PDF、中文版 PDF，各附"日-中-英形态术语表"与"日文名-学名对照表"。用户（分类学家）只看最终结果。

**硬约束（用户定）**
- 每卷全部付费调用 ≤ ¥2（约 0.3 美元）。正文翻译零大模型；大模型至多用于检索表疑点核对。
- 术语必须有出处：中文名只取术语库（yiku）里已核实的译名；没有已核名的类群保留拉丁名，**禁止模型自拟译名**。原因：分类学文本以术语为主，大模型改写不提升质量，反而引入错误；无术语库时译名多半有误。
- 种条目顺序固定：拉丁名 → 日文名 → 中文名 → 文献 → 描述 → 分布 → 图 → 图注。检索表的引导点线不得缺。
- 认不出的图版、图注、检索表项不得静默：必须告警，告警未清零不得出书。
- 大模型引擎仅支持文本输入（无图像输入），故"让模型看图核验"不可行。
- 未经用户明确同意，不写入交付目录；试排只写试排目录。
- 先小样（每卷 10 页）、用户确认后才允许全卷运行。

## 2. 已核实的现状（证据）

- OCR：PP-OCRv5 server，已有三卷逐页行框缓存（每行含框、文本、置信度、页宽）。
- 现有工具只能把整页当图裁出（`pdffigures.py`），无法在整页扫描里定位图版位置。
- 零模型的检索表重建命令（`docstore keys extract|check`）在 p5–14 小样上：2001、2009 的检索表自洽；2007 有 1 处缺陷（`10' p6` 无终点），能被报出。
- 现有审核仅覆盖 `role == body` 的块，约 25%。
- 历史成本：此前同类流程 DeepSeek 累计 ¥27.91（6 个版本），其中"改写"占约 69%。根因：版面结构在 OCR→平文本一步丢失，随后靠模型改写补救。这是本次重新设计的出发点。

## 3. 架构（依赖只向下）

```
原 PDF
 └─ A 版面层（零模型）  OCR 行框 → 角色分区 → 图版检测 → 检索表重建
 └─ B 内容层（零模型）  条目解析 → 术语（已核名/映射库）→ 模板句确定性处理
 └─ C 翻译层            两条独立链：英文链、中文链
 └─ D 审校层            三审三校，覆盖 100% 块
 └─ E 出版层            两遍构建 → 扩展后的 gate → 验收报告
```

**数据主库**：docstore（本地资料库，逐页证据 JSON + FTS 索引）。行框几何写入页记录的新增 `layout` 字段，含引擎版本与 sha256。OCR 缓存目录仅是可清除缓存，不得是唯一副本。
`book_ir.json` 为**派生导出视图**（由页记录 + 条目 JSON 生成，可随时重建）。修订不改它，改动写成补丁，再重新导出。（你们原建议把它当单一事实源；Codex 指出这与现有主库冲突，故降为派生。）

## 4. 各层设计

### A 版面层
1. 持久化几何：把行框从缓存写入 docstore `layout` 字段。
2. 角色分区：按行框几何与文本特征标注 `title / entry_head / body / key / caption / header / footer / plate`；纠斜后取全书中位数估版心，吸附出版刻度，生成可编辑的 `book_style.yaml`（采纳你们 key_layout_spec 第四节思路）。
3. **图版检测（新模块，纯 CV）**：字高指纹 H_char + RLSA + 图注锚定，每页输出置信度。（采纳你们 token-v2 第 5 节核心，细节见第 7 节。）
4. **告警**写入 `plates_alerts.json`，四类：有图注无图框；有图框无图注；置信度低于阈值；图号不连续（图号引用与图注的差集）。人工用 `review_plates.html` 拖框，结果存 `manual_overrides.json`，下次构建优先使用。
5. 检索表：先 `docstore keys extract|check`；改正走 `keys_fix.json`（须写原因）。排版沿用你们 key_layout_spec 的 `bracketed_hanging` 预设：悬挂缩进、点线右对齐、对偶项防拆页、目标区原子化、第二遍构建重映射页码。
6. 核验不让模型看图：①零模型双路一致性（H_char 框与图注锚定框互证，不一致即告警）；②抽样裁图由用户在 `review_plates.html` 目视确认。

### B 内容层
- 条目解析：`treatments.py`（原型）+ 顺序检查。字段缺失或顺序错 → 告警。以"原始候选块清单"核对解析覆盖，零记录即告警。
- 术语库分两类，不混用：
  - **yiku**：带出处的已核中文名；中文链唯一可信来源。
  - **映射库**（term_presub）：日→英的共现统计（count/dice），仅用于英文链 Google 初稿前的前置替换；不是中文名来源，会学错，须审核。
- 日文术语 → yiku 需新增"带原文位置的日文词项映射"。未命中词进待核表，由用户或 yiku 裁定。名录、文献、分布模板句零模型。

### C 翻译层（两条独立链）
- **英文链**：日文 → presub 前置替换 → Google 初稿 → 确定性校验。不用模型改写。映射库按 2009→2001→2007 顺序累积学习，成本逐卷递减。
- **中文链**：拉丁名保留；类群与术语只取 yiku 已核译名；无已核名的类群保留拉丁名并标注；描述正文由 Google（日→中）初稿加 yiku 术语确定性替换，冲突进待核表。中文链单独验收，不借用英文链。
- **模型门槛**：仅检索表疑点段可进模型。调用前登记"要解决什么、预期可测改进"，调用后同指标对比，无改进即停用该用法。
- **预算口径**：Google 初稿同样记账（免费则记 0 元并注明；付费计入 ¥2）；两链与审校共用一个账本和一个 ¥2 预算。未知价格不得放行。

### D 审校层（三审三校）
- 审一（确定性）：学名、数字、编号、引导点、顺序、日文汉字残留。
- 审二（术语）：术语表一致性 + 前置替换一致性。
- 审三（异模型抽审）：只审审一/审二未解决或高风险的块。
- 三校：对照原页抽样（图注↔图、检索表偶句、条目字段），抽样数与缺陷数入报告；目视部分用户在预览页确认。
- 覆盖：审核范围从 body 扩到全部角色块；翻译覆盖与审核覆盖分开统计。
- **改动唯一入口**：所有译文修改走"问题单 → 闸口"（旧文必须恰好匹配一次；数字和斜体学名按**出现次数**保护，不得丢）。现有块级补丁命令绕过此闸口，须改走闸口。

### E 出版层
- 两遍构建：`build` → `map-pages`（量页）→ `build --map`（重映射页码）→ `check / qa / gate`，输出到试排目录。
- `gate` 扩展，下列任一不过则非零退出：①图版告警未清零；②审核覆盖率；③花费 vs ¥2；④检索表缺陷；⑤必需报告缺失/格式错/缺页。
- 验收报告：缺陷计数、花费对 ¥2、告警清零证据、抽样页对照图。

## 5. 图版检测验收指标

不用"框与肉眼一致的页占比"单项。在每卷人工标注的分层样本（整页图版、半页图版、多图拼版、纯文字页、检索表页、倾斜页）上报告：
- 召回、精确率；
- IoU 中位数与 P10；
- 图注↔图版配对正确率；
- **告警召回**：人工标出的坏页中被告警报出的比例（反静默的核心指标）。

阈值待阶段 0 看到数据后与用户商定，之前不承诺数字。

## 8. 请评审者回答的具体问题

1. **图版检测**：对"整页扫描、无文字层、老旧日文志书"，H_char + RLSA + 图注锚定是否足够？有无已发表的基准或开源实现显示在此类扫描上的召回/精确率？应否先加 token-v2 的图像预处理（去霉斑、去透字）再检测？给出依据。
2. **零模型能走多远**：日→英用 Google 初稿 + 术语前置替换、日→中用 Google 初稿 + yiku 确定性替换，不做任何模型改写，对分类学描述文有没有已知的系统性失败模式（如形态术语被机翻成通用词、学名被破坏）？哨兵掩码能否解决？有数据吗？
3. **两条独立链 vs 英文枢纽**：中文版直接日→中，与"日→英→中"哪个对形态术语更可靠？有无文献比较？
4. **日文术语 → 中文已核名的缺口**：yiku 对日本多毛类类群的覆盖率未测。若覆盖低，中文版大量保留拉丁名，是否有更稳的可追溯来源（如日本海産多毛類目録、WoRMS 中文名、中国动物志对应条）？注意：我方不允许模型自拟。
5. **预算**：¥2/卷同时含 Google 初稿（可能免费，也可能计价）和检索表模型核对，这个预算是否现实？检索表核对实测约 ¥0.18–0.31/目录，是否应改为完全零模型（仅靠 `keys check` 的图可达性 + 人工）？
6. **三审三校的"模型抽审"**：在"仅审确定性审未解决的块"前提下，异模型抽审是否有必要？有无证据表明它能发现确定性检查发现不了的分类学错误？
7. **验收指标**：第 5 节指标是否充分？分层样本每层最少多少页才有统计意义？
8. **遗漏**：本设计还缺什么？尤其请指出：日文纵排/竖排、ふりがな（注音假名）、旧字体/异体字、表格与图版混排、中日英三语术语表对齐、日名→学名对照的消歧这些问题我方是否漏了。
