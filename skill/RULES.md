# 通用翻译规范（初译与核译共用，任何领域、任何模型）

领域专有规则在 `domains/<领域>.md`，与本文件一起注入。原第 2–4 节（学名、形态术语、学科语境词）已移到 `domains/分类学.md`。

## 0. 忠实的定义（用户 2026-11-15：「我要忠实原翻译，即原来意思，不能偏离」，不是字面意思）

- **忠实 = 意思等价**：信息、逻辑关系（因果、转折、条件、让步）、论证方向、强调与语气、断言强度（限定语、情态）、指代对象，与原文一致。
- **形式不是忠实的标准**：语序、句子切分与合并、词性、主动被动、主题先后都可以按中文习惯重组。逐词对应、保留英文句式不算忠实，只是生硬。
- 检验办法：中文读者从译文得到的意思，与英文读者从原文得到的完全相同，且读起来像中文学者直接写的。
- 专名（书名、人名、机构、地名、命名的学说）用约定俗成的中文名，不逐词翻译；查 yiku → Wikidata（候选须核）→ 都没有则保留原文（`scripts/entities.py` 自动解析并核对）。
- 学名、数字、单位、引注、图表号、检索表编号是事实，一字不改。

## 1. 忠实
- 不删限定语：only / some / generally / at least / nearly / usually / often。
- 情态不改强弱：apparently / appears / seems → 看来、似乎；may / might / possibly → 可能；suggests → 提示；would not appear to be → 看来并非。**「显然」只对应 obviously / clearly / evidently。**
- either…or 是二选一，不是「兼具」；neither…nor 是两者皆非。
- 指代（the latter / former / who / which）按原文结构定，宁可重复名词也不写含混的「后者」。
- 数字、单位、范围原样（600,000 不是 60,000；up to 30 or more → 多达 30 个或更多）。
- 每块首句、末句逐句对照原文：不得凭空加句，不得漏译句首英文（2026-11-13 比测中 Sonnet 初译两处出现）。
- 论证极性回读：evidence for/against、no evidence、not…but 等不得译反。
- 不加原文没有的套语：值得注意的是、有趣的是、遗憾的是、显然。

## 2. 术语（通用）
- 术语按「英文 + 义项」处理，不论哪个领域。学科义不同于日常义、作者下定义或对举、中文有几种译名的词，都是术语。
- 术语表（`yiku table`）分 **HARD** 与 **SOFT** 两节，用法不同：
  - **HARD**（学名；本领域已核来源译名一致者）：必用，不得改译。
  - **SOFT**（多个译名或义项、只有候选、跨领域〔回退〕）：先读「定义/出处语境」判断本书此处的义项，再从列出的译名里取舍，都不合适就按本书语境译；「已核」不等于必用。〔回退〕＝来自其他领域（分类学书回退到进化生物学），只在本领域没有合适译名、义项吻合时参考。
  - 每个出现的 SOFT 术语的取舍，都登记为**术语决策**：`term_decisions.jsonl`，一行一个 JSON，字段 en、zh、sense（义项）、reason（理由）、source（依据的来源与页码，没有依据写空串，不编造）、chunk（块编号）。同一英文+义项全书一个译名；义项不同可以译名不同，但各登记一行。主会话用 `yiku decide review` 裁定，`yiku decide apply --book <书>` 写回术语库（候选；确认后 `--verified` 才记已核）。
  - 环节动物书里，杨德渐、孙瑞平（层级 1–2）的已核译名优先（表中标★首选）；名词委、Futuyma（层级 4–5）只用于非环节动物的通用名词。
- 同一义项全书一个译法。术语每章首现写「中文（English）」，日常词不括注。
- 定稿前必须做「中文通读」（STYLE.md 第 6 节，`--mode polish`）：只读译文按名家手法改顺，改后自动核验引文/图号/学名/术语不变。
- 没有依据的译名标「暂定」并登记；不凭空拟科名、属名、种名（分类阶元见 SKILL.md 第 5 节）。
- 正文统一用已有中文资料的定名（分类学以杨德渐、孙瑞平为准），保持与既往中文文献一致，便于读者对照；不得以异体字、旧字形或词源为由改动权威用字（如 Chaetopteridae 用「燐虫科」，不改「磷」）。
- 拿不准的译名，或词源上另有更贴切译法时，正文仍用通行名，另加译注说明：词源（拉丁/希腊词根及含义）、通行名的由来（形态、习性、旧译）、其他可行译法。例：燐虫科〔译注：*Chaetopterus* 源自希腊语 chaitē「刚毛」+ pteron「翼」，直译可作「毛翼虫」；中文名「燐」取其发光习性，沿用杨德渐、孙瑞平（1988）〕。推测性解释须标「推测」。
- 难懂的术语（直译后读者难以理解者，如 homoplasy 同塑性）：首现处加〔译注：…〕给出中文定义并注出处（名词委条目号、经典译本页码）；全书另附「术语释义」附录，中英文定义对照（中文｜English｜中文定义+出处｜英文定义+出处）。中文定义优先取名词委、Futuyma《生物进化》葛颂等译术语汇编（docstore key Futuyma_生物进化_zh，p.655–674）。
- 环节动物书中出现的非环节动物通用名词（进化、遗传、生态、系统发育方法等），可查 Futuyma《生物进化》葛颂等译术语汇编（yiku 领域 `进化生物学`）；环节动物的阶元名和形态术语只按杨德渐、孙瑞平及 `domains/分类学.md`，不受其影响（用户 2026-11-13）。
- 经典译作、名家论著的译名照用；怀疑有误，写入 `核译/质疑清单.tsv`（en\t经典译法\t出处页码\t质疑理由\t建议译法\t依据），由用户裁定。

## 3. 引证与原书错误
- `(Author, Year)`、`Author et al. (Year)` 原样，人名不译；双人作者 He and Wu → He 与 Wu（He 不是代词）。
- **原文来自 OCR**：疑似排印或 OCR 问题（括号不配对、断词、乱码、字母或图号错位、重复词等），分不清是原书错还是 OCR 错，**不得擅自注〔原书…〕〔原文作…〕**（2026-11-13 试译里初译模型把两处 OCR 错误当成「原书笔误」加了译注）。照上下文合理译出，并在该处标 `[OCR?]`（半角方括号），留给人工对照页图判断；人工确认后才改成正式译注或删去标记。核译者不删 `[OCR?]`，也不为它建议加〔原书…〕注。
- 原书明显笔误：仅当有页图或第二来源确证是原书本身的错，才订正并注〔原文作 …〕；无法核实的订正不做，只注〔原书如此〕。
- 图号、章号交叉引用：核对后订正并注；核不了照原文。
- 引文与图号不得增删改：终稿后跑 `scripts/cite_diff.py`，译文多出、缺失或改了年份/第二作者的引文与图号（有真差异退出码 1）逐条对原文裁定，不凭印象放过。

## 4. 格式
- 中文间不留空格；中英间不强制空格。禁用 U+3000。中文标点，括注用全角（）。
- 小标题层级与原书一致；图注保留「图 N.N」编号与分图字母。
- 草稿前跑 `scripts/split_check.py`：正文流里的图注残段（缩写键串、Scale bar、Fig. N. 起首）、断词和没有说明文字的图注，先移入图注或合并，再翻译。
- 拉丁属名/双名一律保留（斜体）、惯译人名（`person_names.tsv`）用中文、数字与单位原样、yiku 术语每章首现写「中文（English）」：这几条由 `scripts/fidelity_check.py` 确定性核对并修正（直调初译自动跑），模型不必逐条记住，但不得删改拉丁名与数字；标题的中英对照用 `scripts/heading_bilingual.py`。
- 原文里独占一行的页码标记 `<!-- p.13 -->`（原书页码）原样保留在译文对应位置，不翻译、不改写、不增删；种名按原书页的格式规则（领域包）靠它判断。
