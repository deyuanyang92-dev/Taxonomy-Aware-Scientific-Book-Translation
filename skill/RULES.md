# 通用翻译规范（初译与核译共用，任何领域、任何模型）

领域专有规则在 `domains/<领域>.md`，与本文件一起注入。原第 2–4 节（学名、形态术语、学科语境词）已移到 `domains/分类学.md`。

## 1. 忠实
- 不删限定语：only / some / generally / at least / nearly / usually / often。
- 情态不改强弱：apparently / appears / seems → 看来、似乎；may / might / possibly → 可能；suggests → 提示；would not appear to be → 看来并非。**「显然」只对应 obviously / clearly / evidently。**
- either…or 是二选一，不是「兼具」；neither…nor 是两者皆非。
- 指代（the latter / former / who / which）按原文结构定，宁可重复名词也不写含混的「后者」。
- 数字、单位、范围原样（600,000 不是 60,000；up to 30 or more → 多达 30 个或更多）。
- 不加原文没有的套语：值得注意的是、有趣的是、遗憾的是、显然。

## 2. 术语（通用）
- 术语按「英文 + 义项」处理，不论哪个领域。学科义不同于日常义、作者下定义或对举、中文有几种译名的词，都是术语。
- 术语表（`yiku table`）先看出处语境：义项相同，「已核」必用、「候选」可用；义项不同、不明或标「⚠冲突」，按本书语境译，登记 `uncertain_terms.tsv`。
- 同一义项全书一个译法。术语每章首现写「中文（English）」，日常词不括注。
- 没有依据的译名标「暂定」并登记；不凭空拟科名、属名、种名（分类阶元见 SKILL.md 第 5 节）。
- 正文统一用已有中文资料的定名（分类学以杨德渐、孙瑞平为准），保持与既往中文文献一致，便于读者对照；不得以异体字、旧字形或词源为由改动权威用字（如 Chaetopteridae 用「燐虫科」，不改「磷」）。
- 拿不准的译名，或词源上另有更贴切译法时，正文仍用通行名，另加译注说明：词源（拉丁/希腊词根及含义）、通行名的由来（形态、习性、旧译）、其他可行译法。例：燐虫科〔译注：*Chaetopterus* 源自希腊语 chaitē「刚毛」+ pteron「翼」，直译可作「毛翼虫」；中文名「燐」取其发光习性，沿用杨德渐、孙瑞平（1988）〕。推测性解释须标「推测」。
- 难懂的术语（直译后读者难以理解者，如 homoplasy 同塑性）：首现处加〔译注：…〕给出中文定义并注出处（名词委条目号、经典译本页码）；全书另附「术语释义」附录，中英文定义对照（中文｜English｜中文定义+出处｜英文定义+出处）。中文定义优先取名词委、Futuyma《生物进化》葛颂等译术语汇编（docstore key Futuyma_生物进化_zh，p.655–674）。
- 经典译作、名家论著的译名照用；怀疑有误，写入 `核译/质疑清单.tsv`（en\t经典译法\t出处页码\t质疑理由\t建议译法\t依据），由用户裁定。

## 3. 引证与原书错误
- `(Author, Year)`、`Author et al. (Year)` 原样，人名不译；双人作者 He and Wu → He 与 Wu（He 不是代词）。
- 原书明显笔误：订正并注〔原文作 …〕；无法核实的订正不做，只注〔原书如此〕。
- 图号、章号交叉引用：核对后订正并注；核不了照原文。

## 4. 格式
- 中文间不留空格；中英间不强制空格。禁用 U+3000。中文标点，括注用全角（）。
- 小标题层级与原书一致；图注保留「图 N.N」编号与分图字母。
