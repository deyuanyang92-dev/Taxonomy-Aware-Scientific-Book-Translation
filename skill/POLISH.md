# 中文润色（专业书籍译稿，S7 表述）

目标：译稿意思已核对，最后一遍只改中文表达，让它读起来像中国学者直接写的；**事实一字不动**。
证据与取舍：`docs/zh_style_evidence.md`（本土教科书、本土论述文、名家中译本与我方译稿逐项计数）。

## 1. 先量，再改

```bash
python3 scripts/zh_polish.py 译文.md -o WORK --dry          # 候选段数、批数，不调用模型
python3 scripts/zh_polish.py 译文.md -o WORK                # 润色 codex-sol，意思核对 cursor-composer（默认）
```
产出 `WORK/polished.md`、`WORK/polish_report.md`（全书指标前后、逐段对照、被拒段及原因）、`WORK/polish_log.jsonl`。
润色后若有原文，再跑 transqa（`auto_translate.py check` 或 `transqa.check_all`），确认数字、学名、检索表未变。

## 2. 我方译稿的真问题（计数，不是印象）

| 问题 | 我方 | 本土 | 改法 |
|---|---|---|---|
| 句子切得太碎 | 句长中位 21–23 字 | 29–37 字 | 前后紧密相关的短句并成自然长句；一句仍只讲一件事 |
| 「该」 | 1.8/千字 | 0.3–0.5 | 指代清楚就省；或「此」「这」、重复名词；分类描述中「该种」「该属」可留 |
| 「以及」「然而」「关于」 | 0.4–1.5 | 0.02–0.5 | 不逐个对译 and / however / on：「和」「与」、顿号；转折已清楚就省，需要时「但」「不过」；「关于……的研究」→「……研究」 |
| 「被」 | 2.4–3.2 | 1.2–1.8 | 「被认为是」→「一般认为」；「被用于」→「用于」；「被发现于」→「见于」 |
| 「对……的」名词化 | 1.4–1.9 | 1.2–1.5 | 「对……的理解」→「理解……」 |
| 「一个」「它们」 | 偏多 | — | 不需要数量、指代时省去 |

**不是问题**：「的」的密度（与本土相同）。不要按「一句两个『的』就改」去删。

## 3. 不润色的

- 标题、检索表、异名录、文献、索引、图注、表格。
- 条目体描述（「体长 2–3 mm。口前叶圆锥形。触手 3 对。」）：志书与检索表的电报体是规范写法，不并句、不口语化。脚本自动跳过（`zh_style.is_description`）。

## 4. 闸口（任一不过，保留原文）

- ASCII 串（学名、命名人、年份、数字、图号、引文、括注英文术语）与斜体内容逐项相同；
- 否定词（不、无、未、非、没、否）与限定语（可能、或许、似、约、通常、一般、多数、少数、仅、偶）数量不减；
- 引号数量、范围词（任何、所有、均……）、时间词（此后、最初、仍……）不减少；
- 汉字数在原文 80%–125%；字符相似度 ≥ 0.5（防整段重写）；翻译腔得分不升高；
- **第二模型逐段判定意思等价**（指代、程度、时间、因果、引号含义），有疑问即不替换；被拒的段带拒绝理由重做一次。
  依据：盲评中只有脚本闸口时 7 段有 3 段细微漂移；加第二模型核对后 7 段 0 处实质差异（docs/zh_style_evidence.md §7）。

## 4b. 不改的（白名单，借 GitHub 去 AI 腔技能的否决表并经计数核实）

被动（施事未知或不重要时）、术语性名词化、引用句式、序数小标题、「首先/其次」、合理的破折号与长定语，在学术译稿里是正常写法；
GitHub 上「去 AI 腔」词表（通过、进行、当……时、非常、不是……而是、综上所述等）在我方译稿里计数**不超本土水平**（docs/zh_style_evidence.md §8），不据此改。

## 5. 确定性检查（`zh_style.check_lines`，0 token）

标题末尾句号、衍字（具具、的的）、顿号接转折分句（、但 / 、却）、残留假名、中文里的半角引号、译者套语（值得注意的是、值得一提的是、众所周知：原文无对应时删）。

## 6. 与其他规范的关系

- 译名、术语：yiku 与 RULES.md 为准，润色不改已核术语。
- 句式总则：STYLE.md §3、§5、§6（先结论后条件、名词化改动词、被动改主动、括注克制、人名）；本文件以计数修正了 STYLE.md §6「超过约 60 字就拆」——我方译稿的问题是拆得太碎，60 字以内、意思连贯的句子不拆。
- 写法以本土作者为准，名家中译本同样有翻译腔（Mayr 中译「然而」1.21/千字），只学其译名，不学其句法。
