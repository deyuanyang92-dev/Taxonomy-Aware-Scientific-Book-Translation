## 2. 学名与科名
- 属、种名保持拉丁斜体 `*Genus species*`；拼写以原书为准。
- **物种名格式（用户 2026-11-13）**：有中文名的种，按原书页计，每页首次出现写「中文名（*Genus species*）」，同页再出现只写中文名；换页后首次出现再写一次拉丁名。没有权威中文名的种只写拉丁名。科及以上仍按每章首现括注。页码取自译文里的 `<!-- p.N -->` 标记，图注每条一个单元；用 `run_batches.py --mode species`（或 `species_format.py`）自动检查和修正。
- 科及以上：用 term_table 给出的中文名，首次出现「中文名（Latinidae）」；表中为「—」者只用拉丁名。
- 属的中文名**只用权威名录里有的**（刘瑞玉2008、动物志）；没有就只写拉丁名，不自造（如「毛鳃虫属 *Sabellonga*」是错的，毛鳃虫是 Trichobranchidae）。
- 一个中文名只能对应一个拉丁名；写括注前核对英文原文到底是哪个科。
- 「-ids」类俗称（sabellids, glycerids）译「缨鳃虫类」「吻沙蚕类」。

## 3. 形态术语
- 同一术语在不同科可能有不同规范译名：以 term_table 的分科条为准，通用条（*）兜底。
- 核心对照（已核，全书统一）：antenna 触手｜palp 触角｜tentacular cirrus 触须｜aciculum 足刺｜chaetiger 刚节｜nuchal organ 项器｜biramous 双叶型｜ramus 叶（不译「肢」）｜chaetal inversion 刚毛逆转｜metanephridium 后肾管｜protonephridium 原肾管（名词委作后管肾/原管肾，志书用肾管系，从志书）｜pygidium 尾部｜pygidial/anal cirrus 肛须｜capillary chaeta 毛状刚毛｜prototroch/metatroch/telotroch 前/后/端纤毛环｜median antenna 中触手（首现括注 median antenna，不只写 antenna）。
- 按科已核（2026-11-08）：uncini 齿片（缨鳃虫目、蛰龙介目、帚毛虫科、竹节虫科、磷虫科；锥头虫科/沙蠋科/欧文虫科/毛鳃虫胸区为钩状刚毛）；hooded hook 巾钩刚毛，刚毛的 hood 译「巾」，非刚毛 hood 译罩/盖；paleae 稃刚毛（卷54 帚毛虫科作「稃片刚毛」，外/中/内稃片刚毛，p421；金扇虫科等他科用法待按卷9 原页核，暂不改）；maxillae 上颚、mandible 下颚、jaw apparatus 颚器；interramal 内肢（内肢须、内肢眼点）；operculum 壳盖（龙介虫科、帚毛虫科）、壳盖板（笔帽虫科）。
- **保留原文（用户 2026-11-09）**：专用形态/分类术语每章首现写「中文（English）」，英文取该章原文词形（脚本 `核译/tmp/en_gloss_insert.py` 可批量补，补后须逐条看上下文：曾误补「无刚节（chaetiger）」「伪复型刚毛（compound chaetae）」）。无权威依据的译名一律标「暂定」，正文保留英文，不自行定论；要么自己查到依据再定，要么留待定。
- term_table 标「候选」或「⚠冲突」的术语，以及义项与出处不同的术语：按 RULES.md 第 2 节处理，在 uncertain_terms.tsv 登记，不要硬套。

## 4. 学科语境词
- 系统发育术语以 `terms/系统发育术语_核定.tsv` 为准（用户本人论文用法优先）。要点：
  - recovered X as sister to Y → 「（某某的分析）支持 X 为 Y 的姐妹群」／「X 被发现为 Y 的姐妹群」；recovered as a clade → 「聚为一支」「支持 X 为单系」；recovered within → 「位于／镶嵌于 … 之内」。**不用「恢复」「解析为」**。resurrected / reinstated name → 恢复使用。
  - synapomorphy 共有衍征；apomorphy 衍征；autapomorphy 自有衍征；plesiomorphy 祖征；nested within 镶嵌于；cladistics 支序分类学；cladistic analysis 支序分析；terminal (taxa) 终端类元；rooting 定根；bootstrap 自展；subclade 亚支系；polytomy 多歧分支（名词委《动物学名词》2021）。
  - grade → 演化级（不是阶元）；clade 支系；sister group 姐妹群；monophyletic 单系；paraphyletic 并系；polyphyletic 多系；phylogenomic 系统基因组学（不得漏「系统」）。
- review(s) → 综述（不是修订）；revision → 修订。
- progenesis / progenetic → 性早熟（neoteny 才是幼态延续；paedogenesis 幼体生殖）。
- abyssal 深渊；pelagic 远洋／大洋性；boreal 北方（寒温带）；anchialine 滨海咸水洞穴。


## 5. 分类表述（形态描述）——学志书写法（2026-11-10，计数均为 OCR 全文实数）
形态描述段落、图注、术语表释义按志书写法，不按普通译文写法。规律与例句详见 `/mnt/p/翻译-译作/一些经典译作/参考库/志书分类表述/文风笔记.md`（第 1–5 节）；总论知识见同目录 `分类学基础_志书总论.md`。已核的要点：
1. **具/无 + 阿拉伯数字 + 量词**：「具2个小触手，无中央触手，1对触角具乳突状的端节」（卷33 p405）。卷33「具1」628 次、「具2」331 次，「1对」428 次 vs「一对」7 次；本书译文原先 0 次「具1/具2」——这是最大差距。描述段落里数量一律阿拉伯数字（近海1988 多用汉字数字，以新志书为准）。
2. **电报式短句**：主语出现一次，逗号连接，形状作谓语：「疣足亚双叶型，背须突锥状，腹须细指状，背须大于腹须」（卷33 p405）。
3. **比较用「长于/短于/大于/约等长」**：卷33「长于」197 次 vs「比…长」19 次。
4. **有无**：present or absent →「或有或无」「有或无」，不用「可有可无」（成语，意为无关紧要；2026-11-10 读者指出）。
5. **方位**：dorsal 面 →「背面/背部」；dorso-lateral →「背侧」（志书「背外侧」0 次；卷54「2个背侧叶」、卷9「内背侧」）；视角「背面观」只用于图注（志书描述句不用）。
6. **刚毛**：spinulose →「具小刺」（卷9 28 次、卷33 51 次；「棘刺」主要见卷54）；刚毛名＝「复型/简单型 + 齿式 + 形状 + 刚毛」。
7. **图注**：「A.体前部背面观；C.第9刚节疣足前面观」（卷33 p406）。

## 7. 外部审查意见的裁定（Codex 等，2026-11-10）
1. 忠实度问题（漏 usually/only/may、引文缺失、范围误读、数字）：对照英文原句即可裁定，确认后经 issues 闸口改。
2. 用字问题（「更精确」的方位词、术语换字）：**先查志书**——知识库/OCR 计数 + 2 条原文例句；志书有惯用写法就按志书，驳回审查意见并写明计数。字面更精确不等于合乎中文分类学惯例。
3. 术语定名：按 TERMS.md 次序；志书没有的查名词委（`scripts/termonline_lookup.py`），记书名、版次、条目编号。
4. 裁定逐条记入审查目录下的 `Claude裁定_<日期>.jsonl`：采纳/驳回 + 依据。
5. 发现一类问题后，全书扫同类（审查常只抽样）。
