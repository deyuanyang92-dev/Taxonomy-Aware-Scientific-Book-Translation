# 领域包：<领域名>

新书属于新领域时，复制本文件并改名为 `<领域名>.md`，文件名须与 yiku 的 `--domain` 一致。只写本领域独有的规则，通用规则留在 `../RULES.md`。

## 1. 适用范围
书目：…；yiku 领域名：…

## 2. 术语依据
本领域的权威来源，按优先级列出，写明书名、版本和本地路径。经典译作、名家论著在本领域内排最高级。

## 3. 领域用字
同一英文词在本领域的固定译法，以及与其他领域的区别。例：population 在物种概念领域译作「居群」（洪德元2016 p.980），在生态学中译作「种群」。

## 4. 专名
人名、地名、机构名、书名的译法惯例，是否保留原文。
