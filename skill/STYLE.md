# 译风指南（硬规则见 RULES.md；具体译名在 yiku）

只记通用的中文表达原则，不逐词列举。各参考书的原始笔记在 `/mnt/p/翻译-译作/一些经典译作/参考库/<来源>/文风笔记.md`。

## 1. 总则
- 先忠实，后通顺。通顺只靠拆长句、调语序、词性转换、补出隐含主语，不添加原文没有的信息和评价。
- 引用他人的英文定义：先给中文译句，紧接括注英文原句。
- 译名有分歧且影响理解时，用脚注交代各译法及其学科归属。

## 2. 领域用字
- 每个领域以该领域最高来源的用字为准：思想史、进化生物学以名词委和经典中译本为准（经典中译本有可核实的误译，见第 4 节，术语须核，不盲从）；分类学以动物志和用户核定为准。具体译名查 yiku，不在本文件列举。
- 同一本书内用字统一，不跨领域混用。

## 3. 句式
- 长后置定语、关系从句前置成「……的」；过长时拆成小句。
- 同一短语前后一个说法。
- 语气不加强不减弱：as a rule 译「通常」，不译「一律」。

## 4. 对照经典译本的教训（2026-11-13 比测：Mayr《生物学思想发展的历史》、Futuyma《生物进化》葛颂等译；`/mnt/p/翻译-译作/_比测/2026-11-13_*对照/结果.md`）
学它们的表达：
- 英语式松散结构，有意义完全对应的成语就用成语化解（in any simple manner → 一蹴而就），不为用成语而改义。
- 学科惯用搭配分清：-ism 译「主义」（Mendelism 孟德尔主义、Darwinism 达尔文主义），theory 译「学说/理论」；同一书中二者不混。
- 关键词有歧义时，首现处用括注式释义（不变系列（世系））。
避它们的坑（两位评委独立判为重大错误、并经原文核实）：
- 论证极性：evidence for / against、no evidence that、not … but 等，译后回读一遍，确认没有译反。
- 生态学概念不混：niche 生态位，habitat 生境。
- 种下单位不升格：race / geographical race 译「宗」「地理宗」，不译「种」。
- 宗教头衔照实：Reverend 牧师，Bishop 主教，Archbishop 大主教，Archdeacon 会吏长；不确定的保留原文。
- 哲学/思想史固定术语用学界通行译名：argument from design 设计论证，natural theology 自然神学。
我们自己的坑（Sonnet 初译）：块首凭空加译一句、块首英文句漏译。核译必须逐句核对每块的第一句和最后一句。
