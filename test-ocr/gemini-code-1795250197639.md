## 第二步：实现 5 维自动质检器（`src/04_qc_router.py`）
对每一页提取以下 5 类**不依赖金标即可在线计算**的质检特征（未来直接用于 400 万页生产分流）：

### 1. 置信度分布（严禁只看平均值）
- `conf_mean`：整页行/词平均置信度
- `conf_p10`、`conf_p05`、`conf_min`：最低 10% 分位、最低 5% 分位和单行最低分（抓局部糊字、小号脚注、哥特体段落）
- `low_conf_line_ratio`：置信度 `< 0.85` 的行数占比；`very_low_line_ratio`：`< 0.75` 的行数占比

### 2. 静默漏行检测（基于图像墨水覆盖率）
- 对原图（从 `/dev/shm/ocr_tmp` 或按需内存渲染，用完释放）做自适应二值化并提取**版心内文字尺度的连通域**（自动过滤页边黑边、噪点以及面积过大的插图/框线连通域；若有版面检测的 `Figure/Picture` 框则直接掩膜排除）。
- 计算 `missed_ink_ratio` = **未落入任何 OCR 检测框内的文字墨水像素 / 版心总文字墨水像素**。
- 当 `missed_ink_ratio > 0.12` 时打标记 `FLAG_MISSED_TEXT`（专门拦截“漏掉整段或小号脚注但平均分依然 0.95”的静默灾难）。

### 3. 版面顺序、竖排错配与缩进结构保留检测
- **多栏/顺序异常（`FLAG_ORDER_SUSPECT`）**：基于连续输出行的 `bbox` 几何关系，统计相邻两行出现异常大跨度回跳（如 `y` 显著上移但未发生合法换栏）、左右栏反复交替或行框严重重叠的次数。
- **竖排错配（`FLAG_VERTICAL_MISMATCH`）**：统计文字框高宽比 `h / w > 1.8` 的比例，以及碎片短行（单行字符数 ≤ 2）的异常占比；若比例过高（常见于日文竖排被横排模型切碎）强制告警。
- **缩进/检索表特征（`FLAG_INDENT_KEY`）**：检测行首 `x0` 坐标是否呈多档阶梯分布（如 3 个以上明显左缩进聚类，或高频出现 `1.` / `1a` / `—` / 引导点线等层级特征），并检查当前 JSON 是否完整保留了原始 `x0` 像素坐标（用于确认下游能否靠坐标重建检索表层级，而不必上 VLM）。

### 4. 多语种文本与字符健壮性（防乱码、断词与斜体/重音退化）
- `weird_char_ratio`：非法控制符、连续异常标点或非预期字符集突兀混入的比例。
- `short_frag_ratio`：异常碎行（长度 ≤ 3 字符且非页码/序号）占比，用于暴露表格碎裂或扫描歪斜导致的断行。
- `mixed_alnum_anomaly`：词内部异常混杂数字与字母的频次（典型老铅印 OCR 错字：`1`/`l`、`0`/`O`、`5`/`S` 或拉丁词中间夹杂异常符号）。
- `diacritic_density`：欧系变音符号（`á é í ó ú ñ ü ö ä ß` 等）出现密度，用于后续与金标对比是否发生系统性重音丢失。

### 5. 复杂区块分流标记（区分“整页升级”与“局部块升级”）
- 若上游含版面标签，记录该页是否包含 `Table`、`Formula`、`Footnote`、`Figure/Caption` 数量。
- **三级路由结论（每页输出一个 `route_action` + `reasons` 列表）**：
  - `PASS`：各项指标健康，直接放行；
  - `PATCH_BLOCK`：正文健康，仅局部区块（如单个 `Table` 或少数 `< 0.80` 的行块）需要裁图送 VLM/表格模型重跑；
  - `ESCALATE_PAGE`：触发严重告警（如 `conf_p10` 过低、`FLAG_MISSED_TEXT`、`FLAG_VERTICAL_MISMATCH`、`FLAG_ORDER_SUSPECT` 或低分行占比超标），整页升级给精修引擎。

## 第三步：对照 `gold_real` 做质检校准（最关键）
把上述纯在线 QC 特征与 `03_eval_report.py` 算出的真实金标指标（`cer`、`word_recall`、`order_gap`、`diacritic_acc`、`len_ratio`）按 `page_id` 关联，输出以下 3 份精简分析产物（存至 `runs/qc_audit/` 并同步精简版到 `mnt_bench/reports/`）：

1. **`qc_per_page.csv`**：每页完整特征 + 路由决策 + 真实 `cer` / `order_gap` / `diacritic_acc`。
2. **`qc_summary.md`**：
   - **特征相关性表**：各 QC 特征（`conf_mean`, `conf_p10`, `missed_ink_ratio`, `short_frag_ratio` 等）与真实 `cer`、`order_gap` 的 Spearman 相关系数，找出最靠谱的“抓错指标”。
   - **分级放行帕累托表（阈值扫描）**：扫描不同严格度阈值（例如目标升级率约 10%、20%、30%），分别给出：
     - 放行率（`PASS %`）与局部修补率（`PATCH_BLOCK %`）
     - **放行页的平均 CER / 最大 CER**
     - **危险漏网率（False-Pass Rate）**：被判定为 `PASS`，但真实 `cer > 0.05` 或 `order_gap > 0.05` 或 `len_ratio < 0.90` 的页数与比例。
   - **按 `page_type` 分组体检表**：单栏正文、多栏、表格/检索表、泛黄模糊/德文老体、日文竖排分别有多少比例被放行、多少被精准拦截。
3. **`qc_false_pass.md`（盲区病历本）**：
   - 专门列出 **QC 打高分/放行，但真实误差最大（Top 3–5 页）** 的反例，以及 **CER 最差的 3 页**。
   - 每页仅输出：页型、关键 QC 数值、真实 `cer`/`order_gap`/`diacritic_acc`，以及不超过 **10 行的局部错字 diff**，用来直观排查质检规则还有哪些漏网盲区。
