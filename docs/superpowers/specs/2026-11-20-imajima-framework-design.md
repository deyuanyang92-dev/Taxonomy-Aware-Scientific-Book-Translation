# Imajima 三卷日文志书：框架设计（v5，第 12 节取代 v4 的条目字段与翻译链两处，待用户确认）

日期：2026-11-20。状态：v4 草案，未实现。范围只做 Imajima（用户 2026-11-20 定）。v1 的 4 处致命缺陷与必改项见第 9 节，证据见 Codex 审核记录。

## 1. 目标与硬约束
- 目标：Imajima 2009（361 页）、2001（406 页）、2007（363 页）日文扫描志书 → 英文版、中文版 PDF，附日中英形态术语表、日名-学名表。用户只看结果。
- 每卷总费用 ≤ ¥2，口径含所有付费调用（见 4.C）。翻译引擎默认 Google（gtx 免费端点，记 0 元并注明来源），也可选其他引擎（DeepSeek 等，经 `llm_engines`），引擎由参数指定；付费引擎受 ¥2 闸口约束。`YZZ_BUDGET_CNY` 默认 2，不得设 off。
- 种条目：强制字段＝拉丁名、描述；条件字段＝日名、中文名（无已核名则省略并保留拉丁名）、文献、分布、图、图注（多种共图或引他处时可无）；出现者须保序：拉丁名 → 日名 → 中文名 → 文献 → 描述 → 分布 → 图 → 图注。中、英两版各有 schema。检索表引导点不得缺。
- **试点优先（用户 2026-11-20）**：每一步先在 1 卷 ≤10 页小样上跑通并看结果，达标才扩到更多页；任何全卷运行前须小样结果加用户批准。小样不达标即停下改设计，不得硬跑全卷。
- DeepSeek 仅北京时间 18:00–次日 09:00：运行时必须设 `YZZ_DEEPSEEK_NIGHT=18-9`（`scripts/deepseek_offpeak.py:7,58`）。
- 未经用户同意不写 `日本-imajima/交付/`，试排只写 `book_trial/`。
- 反静默：认不出的图版、图注、检索表项必须进告警；告警未清零，`gate` 拒绝出书。

## 2. 已核实现状（证据）
- 卷与 OCR 缓存：2001=406 页=`966b8423a9d4`；2007=363 页=`858f37873e50`；2009=361 页=`c1ac037a042b`（缓存在 `~/.cache/docstore_ppocr/<hash>/PP-OCRv5_server_200/`）。
- 三本 PDF 每页一张整页图、文字层 0 字符；`pdffigures.py` 只能裁整页。
- `docstore keys extract`（p5–14 小样，零模型）：2001、2009 的检索表自洽；2007 一张表有 1 处缺陷（`10' p6` 无终点），能被报出。
- 审核覆盖：`booklayout/cli.py:625` 起仅审 `role == body`，约 25%。
- 历史成本：DeepSeek ¥27.91（6 个版本），改写占约 69%。根因：结构在 OCR→平文本一步丢失，随后靠模型改写补救。

## 3. 架构（依赖只向下；v2 改动：数据主库归 docstore）
```
原 PDF
 └─ A 版面层（零模型）  OCR 行框 → 角色分区 → 图版检测 → 检索表重建
 └─ B 内容层（零模型）  条目解析 → 术语（yiku 已核名 / 映射库）→ 模板句确定性处理
 └─ C 翻译层            两条独立链：英文链、中文链
 └─ D 审校层            三审三校，覆盖 100% 块
 └─ E 出版层            booklayout 两遍构建 → 扩展后的 gate → 验收报告
```
**单一主库 = docstore。** 行框几何与页面证据写入 docstore 页记录（`pages/<key>/pNNNN.json`，新增 `layout` 字段，含 rows/box/conf/width 及来源引擎）。`~/.cache/docstore_ppocr` 只是可清除缓存，不得作为唯一副本（`docstore/store.py:337`、`docstore/engines/ppocr.py:178`）。
`book_ir.json` 改为**派生导出视图**：由 docstore 页记录加 `treatments.json` 生成，可随时重建；修订不直接改它，而是写补丁（见 4.D），再重新导出。

## 4. 各层设计

### A 版面层
1. **持久化几何**：阶段 1 第一步把三卷行框从缓存写入 docstore `layout` 字段，登记 sha256 与 OCR 引擎版本。此后缓存被清也能重建。
2. **角色分区**：每页按行框几何加文本特征标注 `title/entry_head/body/key/caption/header/footer/plate/table/toc/front_matter/references/index`（references、index 零翻译直通）；纠斜后取全书中位数估版心，吸附刻度，得 `book_style.yaml`（参考 `google-suggestion/key_layout_spec.md` 第四节）。
3. **图版检测**（新模块，纯 CV：字高指纹 H_char + RLSA + 图注锚定）。每页输出置信度。阶段 0 做三路对照（只测，不预设采用）：①纯 H_char+RLSA；②预处理（纠偏、Sauvola 二值化）+RLSA；③本地版面模型（PP-DocLayout_plus-L 或 ndlocr-lite，零费用，非 LLM）。图内 `PROTECTED_LABEL`（比例尺、字母标注）不得擦；裁出图再跑 OCR 查 `CAPTION_LEAK`；图注与图版配对窗口 [N-1,N+1]，图号含 `10'` 类撇号。
4. **告警**（写入 `plates_alerts.json`，不静默）：有图注无图框；有图框无图注；置信度低于阈值；图号不连续。人工用 `review_plates.html` 拖框，结果存 `manual_overrides.json`，下次构建优先使用。
5. **检索表**：先用 `docstore keys extract|check`，改正走 `keys_fix.json`（须写 why）。排版用 `bracketed_hanging` 预设；点线、对偶防拆页、原子目标由脚本负责。
6. **核验不用模型看图**：`llm_engines` 只传文本（`scripts/llm_engines.py:99,112`），v1 的"叠框图交模型"不可行。替代：①零模型的双路一致性（H_char 框与图注锚定框互证，不一致即告警）；②抽样裁图由用户在 `review_plates.html` 目视确认；③如日后接入支持图像的引擎，另行立项并过预算闸，本设计不依赖。

### B 内容层
- 条目解析与校验：`booklayout/treatments.py`（原型）加 `scripts/normalize_species.py check()` 顺序检查。强制字段缺失、出现字段顺序错 → 告警；条件字段缺失不告警。学名斜体：OCR 无字体样式，故先由 ICZN 规则识别器产出 `taxon_span` 实体清单，闸口按实体出现次数守恒，不依赖原书斜体。另加：数值＋单位守恒（μm/mm）；日文 OCR 规范化（旧字体、全角、`ー`/`一`/`-`、检索表撇号 `10'`）置于 B 层最前；日名-学名表主键＝(原书拉丁名, 命名人年份, 卷-页)，附 WoRMS 现行名与冲突标志；三语术语主表 `glossary_trilingual.json`（concept_id, ja_variants, en, zh, provenance, review_status），中英附录同源派生；yiku 缺口以有效拉丁名（WoRMS 归并）为枢纽查中文名，不以日文名作主键。
- 术语库分两类，不混用：
  - **yiku**：带出处的已核中文名；中文链唯一可信来源。
  - **映射库**（`term_presub`）：日→英的共现统计，仅用于英文链的 Google 初稿前置替换，不是中文名来源（`scripts/term_presub.py:1`；映射会学错，须带 count/dice 审核）。
- 未命中词进待核表，由用户或 yiku 裁定，禁止模型自拟译名。名录、文献、分布模板句零模型。

### C 翻译层（两条链）
- **引擎**：`--engine google`（默认）| `deepseek-flash` 等；缓存键含 (源文规范化 sha256, 目标语, 术语库版本, 引擎版本)，sqlite 已有（`auto_translate.py`），补键字段。
- **英文链**：日文 → 术语锚定（见下，阶段 0 A/B 定：裸译 / 短哨兵 / 源侧锚定三选一，淘汰裸明文 presub 与译后盲替的预设）→ 初稿 → 确定性校验。不用模型改写。映射库三卷顺序累积（2009→2001→2007）。presub 使送译字符增加，gtx 免费无影响，付费引擎须计入。
- **中文链**：条目字段中的拉丁名保留；类群与术语只取 yiku 已核译名；无已核名的类群保留拉丁名并标注；描述正文由 Google（日→中）初稿加 yiku 术语确定性替换，替换冲突进待核表。中文链单独验收，不借用英文链结果。
- **模型门槛**：仅检索表疑点段可进模型；调用前登记目的和预期指标，调用后用同一指标对比，无改进即停用该用法。
- **预算口径**：Google 初稿同样记账。若确认免费，则在 `usage.tsv` 写 0 元记录并注明来源；若付费，计入 ¥2。`gate` 读 `token_economy.spent_cny`（`scripts/token_economy.py:225`）。需先补 `auto_translate.py:594` 附近的 Google 调用记账，否则 ¥2 闸口不真实。

### D 审校层
- 审一（确定性）：`booklayout/audit.py`、`transqa`、`fidelity_check`（学名、数字、编号、引导点、顺序）。新增日文汉字残留规则（`transqa/languages.py:26` 现无此检测）。
- 审二（术语）：`yiku check` 加 presub 一致性。
- 审三（异模型抽审）：降为可选，默认关；先用确定性高危扫描（长度比离群、否定极性守恒、假名残留、数值单位守恒），仅对离群块可选调 `deepseek-flash`，无可测改进即停用。
- 三校：对照原页抽样（图注↔图、检索表偶句、条目字段），抽样数与缺陷数入报告；目视部分由用户在预览页确认。
- 覆盖：审核范围由 `body` 扩到全部角色块（`booklayout/cli.py:625`）。
- **改动唯一入口**：所有译文修改走 `核译/issues/*.jsonl` + `apply_issues.py`。`cmd_patch_blocks`（`booklayout/cli.py:1198`）现绕过该闸口，须改为内部调用 `apply_issues` 校验（old 恰好匹配一次、数字与斜体学名不丢），或在 patch 阶段复用同一函数。补丁记录写 who/why。

### E 出版层
- `booklayout build` → `map-pages` → `build --map` → `check/qa/gate`，输出到 `book_trial/`。
- **`gate` 扩展**（现 `cmd_gate` 只读 qa/check 的 `ok`，`booklayout/cli.py:1335`）：新增读取 ①`plates_alerts.json` 未解决数；②审核覆盖率；③`spent_cny` 与 ¥2；④检索表缺陷；任一不过则非零退出。
- 验收报告 `验收报告.md`：缺陷计数、花费对 ¥2、告警清零证据、抽样页对照。

## 5. 图版检测验收指标（v2 重定）
不用"框与肉眼一致页占比"单项。在每卷人工标注的分层样本（含：整页图版、半页图版、多图拼版、纯文字页、检索表页、倾斜页，每层不少于 N 页，N 由阶段 0 后定）上报告：
- 召回（真图版被检出比例）、精确率（检出中为真的比例）。
- IoU 分布（中位数与 P10）。
- 图注↔图版配对正确率。
- 告警召回：人工标出的坏页中被告警报出的比例（反静默的核心指标）。
阈值在阶段 0 看到数据后与用户商定；之前不承诺数字。

## 8. 风险与未确证
- 图版检测在老扫描上的准确率未实测。
- gtx 为非官方免费端点，有限流与 ToS 风险；官方免费额度（Google 50 万字符/月、Azure F0 200 万字符/月）数字来自评审，未复核当前政策。

## 12. v5 修订（用户 2026-11-20 指出两处硬伤；本节取代第 1 节固定字段顺序与 4.C 翻译链）

### 12.1 条目字段由数据归纳，不写死
- 实际页面（2009 卷 p60）所见：拉丁名＋命名人 → 片假名日名 → 引证（含 pp.、text-fig.）→ 描述 → `分布` ；图版页另有 `Fig.NN` 与 a–j 图注。分类志一般还有异名、模式标本、生态/生物学、备考/讨论、检索表，须以样页为准。
- 做法：阶段 0 取每卷 10 页（条目、图版、检索表、前后附页），主会话通读后产出 `imajima_fields.yaml`（字段名、触发词/版式、是否必有、顺序、样例页）。确定性切分器按它切段；清单外标题行标 `unknown_field`，仅这些页进模型复核。另一模型（deepseek-flash，夜间）独立标注样页并出问题单，主会话裁定。校验规则由清单生成。

### 12.2 翻译链（2009 p60 描述段，gtx，零费用，实测）
裸译失败（已确证）：EN 剛毛節→bristle segments、前口葉→protostomal lobe、囲口節→peristomal segment 且丢失/错配术语；ZH 前口葉→原口叶、囲口節→造口周段。
- **英文链**：日文术语源侧替换为英文标准词后再送 gtx，明显改善（chaetigers、prostomium、peristomium、proventricle、compound chaetae 全对）。仍有缺陷：个别句序错配（antennae 起点）、术语替换处标点吞并。
- **中文链**：日文中混入中文词再送 gtx 更差（"53折"、"花萼起"、"腺胃位于第5、11沟之间"）；英文中转（presub 英文 → gtx EN→ZH）也错（chaetigers→"毛虎"、prostomium→"前口"）。结论：不得让 gtx 自行翻译术语。
- **v5 中文链**：先出英文（presub），再对英文稿做 **英文术语→yiku 已核中文名** 的确定性替换（哨兵 `⟦Tnnn⟧` 保护术语，送译后回填 yiku 中文），其余句子由 gtx EN→ZH 或 JA→ZH 译出。哨兵方案须在阶段 0 A/B 中实测，未验证前不定案。
- **术语库现状（`yiku lookup --domain 分类学` 实测）**：已核有 剛毛節=刚节(?)、前口葉=口前叶、囲口節=围口节、前胃、复型刚毛、咽、触手；缺口：cirrus（只有"阴茎"候选，不适用）、acicula（无）；antenna/palp 同为"触手/触角"已核，存在歧义须按 Imajima 原词（感触手 vs 副感触手）裁定。注意：`chaetiger` 已核为"刚节"，与常用"刚毛节"不同，须核对来源后定。
- **A/B 实验（P0-b）**：同一批 ≥10 段，比较 A 裸译 / B 源侧替换 / C 哨兵，指标：术语命中、黑名单错译词（bristle segment、protostomal、tactile hand、原口叶、造口周段、毛虎）、数字与拉丁名守恒，加人工目视。
- OCR 规范化先于翻译：`．，、`→`。`、异体字（刚→剛、复→複）、双栏阅读序、按句切分。
- 术语缺口表由用户与主会话一次性签核后入库。
