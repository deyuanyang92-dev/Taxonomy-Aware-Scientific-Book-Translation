## 判断与限制
- big 失败原因：旧代码索引带引导点的行用未缩放的 8.6 pt，无引导点的行用缩放字号；统一为样式后全部缩放。只在 body_size 不是 10.5 时可见。未强行复刻旧的不一致。
- pin_glue / pin_mark_size：旧代码里制表符、换行 run 和表格单元段落标记没有字号，继承 Normal。直接继承新样式会让检索表行高少约 2 pt、引导点变长，违反 C.4，所以这些空白 run 与单元段落标记仍固定为 Normal 字号。
- keymodel.render_key 的标题仍同时直接设 bold 与 keep_with_next（现有测试读 run/段落直接值），样式里也有。
- Couplet 段落同样直接设 keep_together（现有测试读直接值），样式里也有。
- 未转换：封面/前置页（frontmatter.py）、imajima.py、表格单元格 run、空占位段落、image_para、TOC_MARK 段落。
- Body First 与 Body 是否应不同：规格标「未确证」；以小写开头的段落用 Body Cont（无首行缩进），其余用 Body。
