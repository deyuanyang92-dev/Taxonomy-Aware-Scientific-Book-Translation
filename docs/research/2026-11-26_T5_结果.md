## 2. 实现

- buildcache.py：新增 file_fingerprint、module_closure（静态 import 闭包，含函数内惰性 import）、fingerprints() 返回 builder/source/all 三组。input_key 只用 builder 组，改 qa/stylecheck/sourcecheck 不再使 DOCX 缓存失效。code_fingerprint() 保留（= all）。
- sourcecheck.py：figure_boxes 加分页缓存 pNNNN.figs.<key>.json；key = PNG sha + dpi + scanfigures 指纹；旧条目写新时删除。
- make.py：make_state.json（src/tr/profile/sc_key/source_fp/sc_done/sc_src）；classify_change 纯函数（full/translation/style/none）；参数 --fast [auto|style]；各闸口耗时写入 make.json gate_seconds 并打印；跳过项写入 make.json 和 gate.json 的 skipped，并打印 "SKIPPED (not checked)"，不当作通过；上次 source_check.json 仍交给 gate。
- 哈希取自 block 字段本身（aligned/1 无 src.hash），比 spec F5 更严。
- release 模式、无 --fast、无上次状态、代码/输入变化：一律全跑。
