# 本地分类资料库调研 → 如何省 token / 加速（2026-11-17）

**库根：** `/mnt/p/翻译-译作/参考资料/`（docstore：`_资料库/`）  
**动机：** 分类书术语重复极高；本地已有大量志书/名录/专著/译稿，应用**检索与表**，而不是再问大模型「这个词怎么译」。

## 1. 家底（本机实测）

| 资产 | 规模 | 对翻译的用途 |
|---|---|---|
| `registry.tsv` | **2948** 份资料，登记页数合计 ≈ **50.8 万** | 唯一资料目录 |
| `docstore.sqlite` | ≈ **5.94 GB**（`docs`/`pages`/`fts`） | 页文本全文检索，0 token 查例句/定名 |
| domain=`分类学` | **65** 份；其中 `text_done` **40** | 可检索正文已入库 |
| 名称库 `中文名总表.tsv` | **1126** 条学名↔中文 | 种/属中文名，禁止模型瞎拟 |
| 名称库 `术语/dec_*.tsv` | 志书与论文抽出的术语表（如志33=145、志54=116、刘凌云=279…） | 直接并入异写/HARD |
| ANNiKEY | **518** 条英文定义 | 形态术语英义，作 glossary |
| `taxa.sqlite` | treatment **203**，name_usage **667** | 记述/名称用法结构化，定名与异名 |
| 已有中译稿 | 如 `Handbook_中译稿`（登记 2137 页） | **挖异写与 google_fixes 的金矿**（0 API） |

环节动物相关（节选）：中国动物志 09/33/46/54、近海与学位论文、Rouse2022、Handbook 四卷、Fauchald1977、Harrison1992、Imajima、Hartmann-Schröder 系列、刘瑞玉/黄宗国名录等。

**缺口：** 动物志 09/33/46/54 等仍多是 `registered`（尚未 `text_done`）——页图/OCR 未完全进可检索库，**术语潜力未释放**。名录与部分论文/英文专著已 `text_done`，应优先吃这些。

## 2. 优化原则（相对「问模型」）

1. **定名次序（已有）用本地库执行，不调模型：**  
   用户核定 > 志书正式记述 > 近海1988 > 名录 > 名词委 > 学位论文 > 暂定。  
   实现：`docstore search` / `yiku table` / 名称库，而不是 Opus「猜一个中文名」。
2. **术语重复走表：** 译前用 yiku + 名称库术语 TSV + ANNiKEY 生成**本章 HARD/异写**；Google 后 `normalize`（0 token）。
3. **例句与搭配走 docstore：** 形态词（刚毛/刚毛节/疣足…）用 FTS 抽志书句，注入改写提示或只做脚本校验；禁止为此开一轮 LLM。
4. **从已有译稿挖规则：** `Handbook_中译稿`、项目内已核章节 → `mine_corrections` → 异写/`google_fixes`；下一本自动变省。
5. **结构化 taxa：** name_usage 处理异名/组合名，减少「模型改学名」风险。

## 3. 建议落地（挂优化计划 PR-A/C）

| 优先级 | 动作 | 省 token 方式 |
|---|---|---|
| P0 | 译前 `glossary_build`：yiku ∪ 名称库术语 ∪ ANNiKEY ∪（可选）本章 docstore 命中 | 少送模型、少误译 |
| P0 | 默认档 0：Google + normalize(名称库+yiku) + 护栏 | 大量重复术语 0 token |
| P1 | 报告增加「本地库命中率」：原文术语有多少被表覆盖 | 审计是否真在用库 |
| P1 | 对 `Handbook_中译稿` 等跑 mine_corrections，审后入库 | 一次性挖矿，长期少模型 |
| P2 | 优先 `docstore text` 动物志 09/33/46/54（仍 registered） | 扩大可检索定名与例句 |
| P2 | taxa name_usage → 异名/中文名校验脚本 | 0 token 质控 |

## 4. 不要做的

- 不要为「查个中文属名」去调 DeepSeek/Opus（库里有名录与志书）。  
- 不要把 5.9GB docstore 整库塞进 prompt（只检索本章相关命中，或只进异写表）。  
- 不要等「写够脚本 = 模型」；用库把重复术语覆盖率做上去即可。
