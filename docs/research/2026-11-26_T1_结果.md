# T1/T1b 结果：版面评测框架与 16 页实测（2026-11-26）

## 新增文件
- scripts/bench/layout_pair.py（页配对与抽样）、layout_gt.py（原生 GT + 配准）、layout_score.py（打分、ledger）、layout_adapters.py（Paddle/tesseract 适配、标题层级推断）、layout_run.py（批跑）、layout_paddle_local.py（本机 Paddle）
- tests/test_bench_layout_score.py（16 例，16 过）
- docs/ocr_eval/layout_sample.tsv、layout_gt/、layout_runs/、layout_result.md（排名表）
- LEDGER.tsv 追加若干行（只追加）

## 命令
```
python3 scripts/bench/layout_pair.py sample
python3 scripts/bench/layout_run.py gt --png-dir <cropbox PNG 目录>
python3 scripts/bench/layout_run.py eval --engine paddle-cloud+h --png-dir <dir> --cache <云端 json 目录>
python3 scripts/bench/layout_run.py table --engines tesseract,doclayout,paddle-cloud -o docs/ocr_eval/layout_result.md
```

## 结果
见 docs/ocr_eval/layout_result.md。要点：云端 PaddleOCR-VL 角色 1.00、标题检出 1.00、CER 0.086；标题层级各引擎均不可靠（严格 <=0.434），须靠原生字体或规则。
