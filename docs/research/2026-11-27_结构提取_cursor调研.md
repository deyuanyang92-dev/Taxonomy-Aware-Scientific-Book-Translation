# 结构提取调研（cursor-grok-4.5-high，2026-11-27，未经主线程核实）

**结论（约 850 字）**：原生科学书应用「书签页码 + 印刷目录匹配 + 编号深度 + 字号阶梯」四线索；图用显示框裁切并滤掉标尺/表线；段切用几何启发式。下列工具侧依据含本机调研与公开文档；未能联网复核源码处标 **unverified**。

## 各工具信号与失败模式

| 工具 | 标题层级主信号 | 目录/图/段 | 典型失败 |
|---|---|---|---|
| **pymupdf4llm** `IdentifyHeaders` → `to_markdown` | 全书 span 字号聚类，大字号→`#`…`######`（相对正文字号） | 几乎不专做印刷 TOC；图多为嵌入图导出 | 同字号多级（如 Handbook 节/小节同 9.5pt）塌缩；粗体同号误当标题；目录页当正文标题 **unverified: 确切文件名随版本变，常见 helpers 内 IdentifyHeaders**；[pymupdf4llm](https://github.com/pymupdf/pymupdf4llm) |
| **PyMuPDF** `Document.get_toc()` | **仅 PDF outline**：`(level, title, page)` | 不管印刷目录；无图语义 | 无书签、全 level-1、标题乱/空但页码仍可用；与正文标题不一致 |
| **Docling** | 默认同级；可选 hierarchy：书签 + 编号（`1.1`/`A.2`）+ 字体 | 版面模型给 `section_header`/`caption`/`table`/`figure`；阅读序 | 无编号且字号平的书仍平；扫描依赖 OCR；见 [heading_levels](https://docling-project.github.io/docling/usage/heading_levels/)；本库记于 `docs/research/2026-11-26_structdoc_ocr_layout调研.md` §4.3 |
| **Marker**（Surya 版面） | 检测 `SectionHeader` + `section_hierarchy`（视觉/VLM） | 去页眉脚；图/表块类型 | 权重商用门槛；可“编”结构；对原生 PDF 不保真字体；[datalab-to/marker](https://github.com/datalab-to/marker) |
| **GROBID** | 学术论文 TEI：版面特征+文本模式→`<head>` | 面向论文 front/body/ref；非专著 TOC | 书章结构差；图区弱；双栏专著易碎 |
| **pdfplumber** | **无层级模型**；`chars`/`words` 几何 | 右对齐页码行可手写 TOC；`extract_tables` | 无 role；表策略对无线表/旋转页不稳 |
| **Nougat** | 整页视觉→Markdown 标题 | 不给出可靠图 bbox | 幻觉、漏/重页；非整书版式复原 |

本仓库已落地对照：`booklayout/fontlevels.py`（`number_depth`/`merge_levels`/`assign_levels`）、`contents.py`（`contents_from_pdf_page`）、`pdffigures.py`（`image_placements`/`_is_furniture_or_table`）、`ingest_native.group_blocks`。

## 推荐通用算法（无 per-book 常数）

**A. 章界与层级（优先级）**  
1. `get_toc()`：只信 **page**；level/title 作弱先验。  
2. 印刷 TOC 行 → 模糊匹配正文候选标题（归一化空白/大小写/连字符；允许标题截断），用 TOC 的编号深度或缩进定级，页码对齐章界。  
3. 正文 `7` / `7.4` / `7.4.8`：`depth = 段数`（`fontlevels.number_depth`）。  
4. 无编号：相对 **body 众数字号** 的阶梯（≥约 1.15× 或粗体+衬线切换）+ `merge_levels` 与编号共尺度；冲突记 `conflict` 不硬盖（同 Docling「书签+编号+字体」思路，`调研.md` §4.1）。

**B. 印刷目录页检测（通用）**  
前部页：标题词命中 `Contents|Table of contents|Inhalts*|Sommaire|Índice|目录`（`contents._HEAD_WORDS`）；且 ≥5 行「末 span 为页码、贴栏右缘」或 ≥1/3 行引导点+页码；双栏先分 gutter（`contents_from_pdf_page`）。无点线时必须靠几何右页码，勿只靠正则。OCR 碎块目录易漏检（`2026-11-27_layout_fix_进度.md`）。

**C. 图区（栅格+矢量）与假图**  
- 栅格：`page.get_image_info` 显示 bbox 裁页渲染，勿裸 `extract_image`（`pdffigures` 文档）。  
- 矢量：`get_drawings` 聚类；滤除：整簇在上下 ~15% 带、文字面积比 >~35%、纯轴向线/矩形且无 fill/曲线且文字比≥~5% 的表网（`_is_furniture_or_table`）。  
- 扫描页：整页大图 + 无 `Fig.` 图注 → 标 furniture/底图，不入 figure；多页重复 digest 当页眉标尺（`REPEAT_PAGES`）。图与 caption 一对一链接后插入阅读序。

**D. 段落**  
行簇：样式变、行距>约 0.5×字号、首行缩进、上行明显短于栏宽、粗体 run-in → 断段（`ingest_native.group_blocks`）；跨页小写续接可后合并。

**落地顺序**：先 outline 页码锚点 → 检出 TOC 页解析条目 → 匹配定级 → 字体阶梯补洞 → 再插 figure 块并跑 likeness 角色序列验收。
