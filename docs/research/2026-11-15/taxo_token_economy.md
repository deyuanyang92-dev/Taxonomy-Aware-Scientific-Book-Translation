# 分类文献省 token 的方法：结构分流 + 经验积累（2026-11-15，Hartmann-Schröder 德→英）

用户要求：「分类文献有自身独特格式，要学习、总结；同类文献后续翻译要高效且越来越准，不能每次从头译」；
「只给 DeepSeek ¥2，能否完成全部 17 份德文（约 1650 页）」。

## 1. 量化：分类文献由什么组成（脚本统计，0 token）

材料：17 份德文论文 OCR 后 479 万字符，`transqa/taxoblocks.kind()` 分块。

| 块类型 | 字符占比 | 说明 |
|---|---|---|
| 描述（电报体） | 66% | 「Prostomium mit vier Augen…」 |
| 叙述 | 8% | 前言、方法、讨论里的完整句 |
| 生态 / 产地 / 分布标签段 | 6% / 5% / 3% | `Ökologie: Substrat: …; Tiefe: …`、`Fundort:` |
| 讨论（Bemerkung/Diskussion） | 4% | |
| 标题、图注、引文、OCR 乱码 | 3% / 2% / 1% / 1% | 0 token 处理 |

重复率（5 份 25 万词，数字与作者名归一）：
- **整句复用省不了多少**：每个不同从句只译一次，全书仍要译 89%；描述 93%。与 Marinov（17% 精确重复）一致。
- 标签段重复高：产地段去重后只剩 45%，生态 86%、分布 77%。
- 描述的「句式统一」在短语层：出现 ≥5 次的 4 词短语覆盖描述词次 26%。

## 2. 试点（1971 Opisthodonta，8 页，64 段）

| 路线 | 送模型改写的段 | 描述段与 DeepSeek 改写稿相似度 | 花费 |
|---|---|---|---|
| Google 初稿 | 0 | 0.82 | 0 |
| Google + 本地术语表 + 从本试点学到的替换规则 | 0 | **0.85** | 0 |
| 本地 OPUS-MT de-en（未微调）+ 术语表 | 0 | 0.76 | 0（CPU 180 句 82 s） |
| DeepSeek 全文改写 + 两模型核对 | 58 | — | $0.007 |
| Codex sol 全文改写 + 两模型核对 | 58 | DS≈Codex 0.86 | 订阅额度 |
| **Lean：只改写叙述/讨论（Codex），其余 Google+库** | **10** | 同第 2 行 | 订阅额度 + 核对 $0.003 |

读法：描述段的「Google+库」与模型稿的差距（0.85）已与两模型稿之间的差距（0.86）相当；Google 的错几乎全是术语与固定搭配
（palpi、tentacle cirrus、acicles、bristles、front/back、edge），这些由本地库规则零成本修正。
OPUS-MT 未经领域训练明显更差（crirrels、skinned vagina、not arranged = nicht gegliedert），但它可以用我们核过的句对微调，Google 不能。

## 3. ¥2（约 $0.28）DeepSeek 能否完成全部？

全文直译估算：输入 1.33M、输出 1.13M token → **$0.88（¥6.3）**，78% 是输出。全文意义核对按试点比例约 $0.9。
因此只有「大部分英文不由 DeepSeek 生成、核对只看风险句」才能进 ¥2：

| 项 | 做法 | 估算 |
|---|---|---|
| 初稿 | Google（或微调后的本地 MT）+ 本地库规则 | $0 |
| 改写 | 只改写叙述 + 讨论（12%） | ≈ $0.11 |
| 核对 | 脚本先标风险句（数字/否定词/学名/长度比/否定数不符、机翻低置信），只送这些句 | 风险句 20% 时 ≈ $0.18 |
| 合计 | | **≈ $0.29（¥2.1）**，边界；风险句降到 15% 内即进 ¥2 |

未确证：风险句比例与「只核风险句」漏掉的错误数，需在第二份文献上实测。

## 4. 经验积累机制（每译一份，下一份更省更准）

1. **术语表**（按语言对 + 领域共享，不按书）：源术语 | 定名 | 异写 | 依据。
2. **后编辑规则**：`scripts/mine_corrections.py` 从「初稿 vs 终稿」挖一致的替换，经审核写入术语表异写列；
   1971 一篇就挖出两模型一致的 16 条（bristles→setae、end member→blade、edge→margin、Taf.→Pl.…）。
3. **块分流规则**：`transqa/rules/taxo_labels.toml`（段首标签词，按语言加一行即可）。
4. **已核句对**：作为改写提示词的例句（检索最相似几条），并作为本地 MT 的微调数据（攒到 3–5 千句后实测）。
5. **OCR 规则**：`docstore/latinfix.py`、`docstore/rules/lang_words.toml`（模型兜底发现的错误回流成规则）。

## 5. 下一步（按收益排序）

1. 风险句核对（`check --risky-only`）：脚本选句，只送风险句；在第 2 份文献实测漏检。
2. 术语表移到共享位置（同语言对、同领域的所有书共用），每份文献译完跑 mine_corrections 并审核。
3. 攒够已核句对后微调 OPUS-MT de-en（需装 cu126 版 torch；当前 torch cu130 与本机驱动不兼容，只能 CPU），比较「微调本地 MT + 库」与「Google + 库」。

已实现 `--risky-only`，用于 `check` 阶段按段过滤模型输入，叙述与讨论段始终保留。
用法：`python3 scripts/auto_translate.py check SRC.md TGT.md -o WORK --sl de --tl en --glossary G.tsv --risky-only`。
源译段数不一致时保留整页；终稿仍保留所有段落，缓存区分全文与风险段检查。
控制台显示保留段数与原文段落字符占比；术语表越完整，术语风险误报越少。

## 6. 风险段选择（`transqa.taxoblocks.risk`）离线评估（0 token，1971 试点三条路线的核对日志作真值）

信号：数字不符、否定词少于原文、长度比 <0.6 或 >1.6、德文功能词残留、学名（拉丁词尾种加词）缺失、
**术语表源术语在原文出现而定名不在译文**、模型整段改写过。

| 路线 | 风险段字符占比 | 覆盖核对查出的真问题 |
|---|---|---|
| Lean（Google+库，只改写叙述/讨论） | 无术语信号 49% / 加术语信号 83% | 5/21 → 15/21 |
| DeepSeek 全文改写 | 98%（整段改写全算风险） | 3/3 |

读法：Lean 的风险主要是 Google 术语没被规范化（tentacle cirrus、end phalanges、Seta terminals）。
与其送模型核对，不如把这些补成异写（含单复数词形）让脚本直接改——这正是「每译一份就积累」的部分。
剩余漏检 6 条：题名页刊名被 Google 翻译（ZOOLOGICAL MEDEDELINGEN）、大写标题、OCR 读坏的文献条目被翻译
（文献条目应 0 token 原样保留，已加 reference 规则）。

## 7. 「重复」在哪一层？（用户：分类文献大量重复，能否总结规律优化翻译）

17 份德文、描述与标签段，按层量化：

| 层 | 重复度 | 能否据此零 token 翻译 |
|---|---|---|
| 整句/从句（数字、作者归一） | 去重后仍需译 89% | 否：整句翻译记忆只省约 1 成 |
| 句子骨架（名词→N、数字→#、学名→SP） | 骨架出现 ≥2 次只覆盖 23% 字符；不同骨架 5.2 万个 | 否：描述是术语的自由组合，不是固定句型 |
| 短语（2–5 词） | 最常见 1000 个覆盖 38% 词次，2000 个 45% | 部分：可统一译法、作风险检查 |
| 术语（名词词形） | 1.2 万词形，5 千个覆盖 95% | **是：规律主要在这一层** |

短语表（`scripts/phrase_table.py`，2000 条，DeepSeek 一次性定规范译 $0.015，Google 同批译免费）：
Google 与规范译法不同的 803 条中，只采纳「规范译法含术语表定名、Google 没有」的 272 条为异写
（其余多是措辞差异，短语残片单独译时 DeepSeek 的英语未必更好）。在 1971 试点上短语表只多修 4 处——
Google 在上下文里的译法与单独译短语时不同，字符串难精确匹配。

**真正起作用的是术语级、以原文为锚的规则，并且越积累越好**（1971 试点，描述/标签/图注 38 段，0 token）：

| 步骤 | 风险段 | 与 DeepSeek 改写稿相似度 |
|---|---|---|
| Google 原样 | 21 | 0.815 |
| + 术语表（44 条） | 13 | 0.828 |
| + 修正：异写全局按长度从长到短（否则 bristle→seta 先换，bristle segment→setiger 失效，得 seta segment） | — | — |
| + 风险检查整词匹配（Borsten 不再匹配 Borstensegmenten） | 10 | — |
| + 从核对日志补的词形异写（end phalanges、terminal segments、seta terminals → blades…） | **6** | 0.836 |

结论：分类文献的「重复」可以利用，但杠杆在术语与词形层，而不是句子层；每译一份，核对与挖掘发现的术语错法
补进异写表，下一份的风险段就更少，交模型核对的量随之下降。这就是不训练模型也能积累的「经验」。
