# Codex 复审 r3（2026-11-23）与裁定

- **高｜`docstore/textify.py:326`**　云端漏识非空白页后，若 PP-OCR 返回空串、Tesseract 读出正文，现有投票仍可选中空串，整页按空白入库并计入完成。已用内存读数复现。应在写库前剔除非空白页的空读数，所有读数均为空时保留失败状态。
- **高｜`docstore/textify.py:326`**　拉丁语路由把 `ppocr → tesseract` 降级链改成两个都必须运行的引擎。已复现 PP-OCR 抛错后 Tesseract 调用次数为 0。应按顺序尝试本地引擎，首个有效读数即可入库，并按实际引擎署名。
- **高｜`docstore/textify.py:344`**　显式多引擎模式把所有页预先交给进程池，各进程的单页云调用没有共享停止信号。一页触发配额后，其他已启动的页仍可首次提交或重试上传。应由父进程统一调度云提交，或让所有工作进程共用提交闸门。
- **高｜`docstore/engines/paddle_vl.py:331`**　批量路径检查 `stop` 后才读取令牌并 POST。已复现在读取令牌期间置位 `stop`，随后仍发出 1 次 POST。应先准备请求，再用同一同步机制协调停止广播与新提交的放行。
- **中｜`docstore/engines/paddle_vl.py:365`**　轮询先处理 `failed`，后检查截止时间。已复现上限 10 秒、第 11 秒收到 `failed` 后重新上传，第二个任务成功，原块超时被掩盖。应在处理任何任务状态前检查截止时间，超时按 `kind="job"` 结束。
- **中｜`docstore/engines/paddle_vl.py:338`**　提交端返回 `{"code":0,"data":["bad"]}` 时，已复现裸 `AttributeError` 越过块级错误处理，导致整批中断，失败页无法降级。应先校验 `data` 和 `jobId` 的类型，畸形响应转为 `PaddleJobError`。
- **中｜`tests/test_paddle_vl.py:535`、`:525`**　测试核对的是页面 `extra`。共识版本升主后，`store.py:610` 只复制标准字段，实际 Paddle 备选版本会丢失任务标识，首写的降级版本也会丢失失败原因，但断言仍能通过。应在版本升降时保留其元数据，再按 `producer` 定位实际版本逐字段断言。
