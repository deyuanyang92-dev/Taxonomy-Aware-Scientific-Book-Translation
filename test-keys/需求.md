## 一、要做什么
keykit 是独立的检索表工具，放在 test-keys/ 里反复优化，稳定后再并回翻译软件。
远端仓库：https://github.com/deyuanyang92-dev/m2key 。只做检索表，不碰其他正文。

| 编号 | 功能 | 验收 |
|---|---|---|
| F1 | 检查检索表格式（含译后、OCR 后的检索表） | 用户截图里一眼能看出的错要全部报出来：对句编号、去向、点线、右对齐、斜体学名、偶句跨页 |
| F2 | 自动修正格式错误 | 修完再用 F1 检查，结果为零错 |
| F3 | 排版出可发表的 Word 和 PDF | 达到正常发表检索表的样子；Imajima 2001/2007/2009 多科检索表作测试集 |
| F4 | 用性状矩阵制作检索表，支持多阶元混合（检到科，再检科下的属，再检属下的种） | 输入是分类学家整理的性状表，比如 Pectinariidae 综述 Table 1 |
| F5 | 判断哪些性状可用 | 依据作者自己的判断和文献，不能只看数据。不稳定的性状（尾部、环纹、腹中沟这类）不作分叉依据 |
| F6 | 兼容 DELTA：读写 DELTA 数据，和 DELTA 内置 KEY 程序比较结果 | 同一份 DELTA 数据，比较 keykit 的表和 open-delta KEY 的表 |
| F7 | 从检索表评价分类好坏 | 检索表依赖模糊或不稳定的性状，就说明这个类群的分类差、需要修订。结论要指到具体的对句或种对 |
