# keykit 矩阵建表 + 检索表审计：总计划 v2（2026-11-24）

v2 吸收了 Codex 对 v1 的对抗审查（23 条，原文 PLAN_review.md；v1 存 PLAN_v1.md）。采纳了全部 6 条致命意见和大部分高危意见，逐条对应见第 7 节。

依据：survey/notes/*.md（15 份读码笔记）、key2.txt。许可：dimoose、monographaR 为 GPL，只借思路；open-delta 为 MPL 1.1（文件头），公式自行实现。

## 0. 立场（用户 2026-11-24 定）
检索表不好就是分类不好；用模糊、不稳定的性状分种，说明种界没立住。审计不设"作者写得差"的免责分支。
但"分类不好"的结论必须有可复核的证据（具体对句、种对、可行的共同观测），不能由启发式分数直接下判决（Codex #17、#20）。

## 1. 矩阵 IR（keykit/matrix.py）
- Taxon(id, rank, parent_id, name, authority, weight 1-10, name_zh)。id 稳定，不随改名变化。
- Character(id, type: cat|num|count, unit, organ, cost 1-4, reliability 1-10, depends_on: {char: [states]}, phrase_zh/en)。reliability 阈值固定为配置项，默认 ≤4 视为不稳定。
- Cell 的来源标记：observed（本级实测）| inherited（继承）| unrecorded（未录入）。取值分四种，互不混用：
  - 状态集（每态可带频率 0-1）
  - 数值：{typ:[lo,hi], full:[xlo,xhi], unit, closed:(bool,bool)}；count 型步长 1
  - UNKNOWN（原文明确未知）
  - INAPPLICABLE（已知不适用）
- 继承：上级值向下继承，下级可覆写，来源标 inherited。
- 上卷（关键，Codex #7、#8）：**不做逐列取并来判定可达性**。目标节点（科/属）保存其全部后代记录（种级行）；可达性按"沿路径已问条件，是否仍存在同时满足这些条件的同一条后代记录"判断。逐列并集只用来生成候选问题和显示（如 "(2.0–)3.5–6.2(–8.0) mm"）。数值上卷保留区间并集，不用 min–max 填平空档。权重总量（适用/已知/未知）从原始后代累加，不逐级重加权。
- 导入：Excel/CSV 多 Sheet 模板；DELTA items（& 多态、- 不适用、a-b 区间）；Clavis JSON 后期。
- 校验错误码（M1 验收用）：E01 重名列、E02 空 taxon 名、E03 父链环或悬空、E04 依赖环、E05 区间 lo>hi 或单位缺失、E06 状态不在性状定义内、E07 继承覆写类型不符；W01 整列全同、W02 孤立状态；I01 继承覆写。

## 2. 建表（keykit/build.py）
- 贪心递归，无回溯；最优性不宣称（dimoose、DELTA、rpart 都如此）。
- **路由规则（Codex #2）**：每个 taxon 带"剩余状态域"。对候选问题 q 及两侧谓词 P、¬P，各自把 taxon 的剩余状态域与谓词求交，交集非空才进该支；已知只有红/蓝的种在问"{红,蓝} vs {绿}"时只进左支；UNKNOWN 两支都进；INAPPLICABLE 不可问：只有当前路径已使性状 depends_on 成立时才允许把该性状列为候选。
- **进展条件（Codex #3）**：拒绝空支和任一支保留全部候选的无信息分裂；每条递归边必须使候选集严格缩小或使剩余状态域严格收紧。缓存分"构造中/已完成"两态，命中"构造中"节点报错而非回指成环。
- **高基数性状（Codex #3）**：k 态性状的 2^(k−1)−1 个二分不全枚举。候选只取：单态 vs 其余；有序或数值性状的前缀切分；其余用预算上限（默认每性状 64 个候选），超限记 W03 并只用单态切分。总预算耗尽报构建失败，不静默截断。
- **数值（Codex #4、#5）**：保留每个 taxon 自己的区间，不预先传递合并。阈值只在有序端点之间的候选位置取，两侧成员直接计算；可达性按 full 范围（含极值），评分按 typ。边界语义：闭区间；count 型以步长 1 离散；margin 为绝对量，默认 = 该性状单位下全体 typ 区间并集宽度的 5%，可按性状覆盖；报告同时给"实际交叠量"和"正间隙"。单位换算前后判定须相同（测试）。
  例（回归测试）：A=[0,2]、B=[1,4]、C=[3,5]，在 2.5 切分，左支恰为 {A,B}、右支恰为 {B,C}。
- **打分（Codex #1，本工具自己的完整定义，不是 DELTA 公式拷贝）**：
  - 对一个分裂，组 g 含 n_g 个 taxon（多态/未知进多组，重复计入），W_g=组内 taxon 权重和，n=分裂前 taxon 数。
  - sup0 = Σ_g W_g·log2(n_g) / Σ_g W_g
  - dupf = ((1−v)/v)·((n+8)/(n·log2 n))·(Σ_g n_g − n)，v=varywt 默认 0.8（DELTA User's Guide §5.4 式(5)，v=1 无惩罚；非常规子组再乘 1+100m）
  - cost_eff = 观察成本 × rbase^(5−reliability)，rbase 默认 1.4；已在本路径使用过的性状 cost_eff 再除以 reuse（默认 1.01）
  - su = cost_eff + sup0 + dupf，取最小。
  - 平手：su → cost_eff 小 → 性状 id 字典序。
  - 备选准则 ab：score = a·b/cost_eff；全部乘积为 0 时退为 (a+b)/cost_eff；取最大；平手规则同上。
  - 与 DELTA/dimoose 原式的关系：只借结构，常数 rbase/abase/varywt/reuse 沿用 DELTA 手册默认值并标"待标定"；100、8 来自 DELTA 手册 §5.4，非无依据，沿用。
  - M2 验收要求用丰度不等、含跨支种的小矩阵给出 su 的逐项手算值。
- 记忆化 DAG（Codex #6）：缓存键 = 剩余 taxon 集 + 各 taxon 规范化剩余状态域 + 已问性状集 + 阻塞集 + 路径专属钉标识。键不同则不共享。人工钉对共享节点采用"复制后修改"，不就地改。
- 确认性状：每叶追加 ≤k 个与路径上已问性状独立的性状（不同器官且不同性状 id）；不足 k 个时如实少于 k，不凑数。
- 终止：剩一个 taxon；或无合法分裂。无合法分裂时，只有"两个 taxon 存在互相相容的完整记录"才记 unresolved（附共同可行观测）；否则是构建预算或谓词集不足，报构建失败，不算分类证据（Codex #17、#21）。
- 多态/未知膨胀：max_couplets 超限报错。

## 3. 多阶元混合（keykit/hier.py）
- 目标映射（Codex #10）：给定 scope 与每分支 stop_rank，先验证 scope 内每个种恰好映射到一个目标节点；跳级、缺阶元、同一种有两个预期答案都在建表前报错。
- 三模式：single；linked（科表→属表→种表，子表挂在叶上，借 mergeKeys prune.R:384 与 KeyBase 的 subkey/shortcut）；hybrid（异构目标单表）。
- **linked 透传（Codex #9）**：不是"已问性状不再问"，而是把父表路径上得到的**剩余状态域**传给子表；只禁止答案已被入口条件完全确定的问题，剩余值域内允许继续细分。子表有多个入口时按入口各自回放父表路径。
- 纯度项：su' = su + λ_tax·(1−纯度)。纯度 = 各分裂组中，按指定参照阶元（如属）划分后，最大同阶元后代权重占比的加权平均；跨支阶元按各组权重计。λ 默认 0；取值无文献依据，标"待标定"。
- 单型阶元折叠开关；折叠前后结果须相等（测试）。

## 4. 检索表 IR 与校验扩展（Codex #22）
现有 ir.Lead 只有单个字符串 target，Couplet 只有一个 backref；fix.check 会把合法 DAG（1→2/3，2/3→4）报 S3。
- 新增：Lead.target 增加类型（jump | taxon | subkey），跨表引用带 key_id；终点是集合（共享叶）。
- 新校验器 check_graph：按真实入口检查引用、可达性、环；合法菱形不报错；不可达子图、跨表环报错。
- 导出再读入后终点集合须等价（测试）。

## 5. 审计（keykit/audit.py）
全部确定性，无大模型。每条证据指向具体对句/种对，附原文位置。结论分三档：证据缺口、矩阵未给出区分、分类证据。

- A1 性状可观察性，拆成两种证据，不混算：
  - 文字缺陷：缺性状、缺比较对象、缺操作符、缺单位；"其余状态"在前支已穷尽列举时是严格补集，不算缺陷。
  - 矩阵稳定性：reliability≤阈值的性状被用作分裂，位置口径固定为"该对句在 DAG 上的最小深度"。
- A2 对句间区间：对齐性状、测量对象、发育期、单位；解析 ≤ ≥ 至多 至少；分别报告单性状交叠，以及**两支完整谓词的交集**，后者给出一个同时满足两支的具体取值。仅单性状交叠而完整谓词不相交的，不报。
- A3 多出口：以稳定 taxon id 合并出口；按互异且可满足的路径条件计数；分别标已知多态、未知造成的复制、结构复用（共享子表）。展开与折叠同一 DAG 得同值（测试）。
- A4 种对：输出"共同适用且已知的性状数"、"独立诊断数"、可靠度、联合约束是否相容。共同可比为 0 时判"证据缺口"，不是同物异名；有充分覆盖且独立诊断数为 0 才判"矩阵未给出区分"（候选同物异名/隐存种）。边际区间相交不足以证联合相容，须用完整记录判。
- A5 缺失：分母=适用项；单列"适用性未定"、种级实测覆盖、继承覆盖；零分母规定输出 n/a；"需重描述"绑定到具体缺项。
- A6 产地/生境/寄主代形态：删去已结构化路径上的生态谓词，重算该对种是否仍可区分；删后合并才报，附被删谓词。文本仅出现生态词不触发。
- A7 不可分：只在两个 taxon 存在互相相容的完整记录时才报，并附共同可行观测。**步数与树形效率（E_shape 等）单列为"鉴定效率"，不作分类证据**（Codex 反例：16 种各有专属性状，唯一可鉴，等权平均 8.4375 步 vs 平衡树 4 步）。key2 中按出口路径数算 n 的写法有误，须按 taxon 数。
- A8 名录对照：固定名录快照（版本、截止日期、区域、阶元、纳入条件），按接受名 id 比对；分别输出范围内遗漏、后续名称变更、重复收录、未匹配记录；WoRMS/GBIF 冲突的裁定规则写入报告。走 oworms，不在 keykit 自拉。
- 反推矩阵（L1→L2 的桥，Codex #19）：同一路径内取交集；路径之间保留析取；"同一路径先问 红或蓝，再问 红"是相容；只有路径交集为空才记表内矛盾。每格四态：未问、解析失败、原文明确未知、独立观测。反推出的矩阵标 provenance=derived-from-key；由它重编译得到的 A4/A7 证据不与表文本证据重复计数。
- 汇总（Codex #20）：先按（属、种对、性状、证据来源）去重；公布各项分母和覆盖率；同一缺失单元格只计一次。校准前只输出排序与证据清单，不给高/中/低分档。校准需要独立标注的属级参照，并划分校准集/留出集；参照数据（Packer 2024 的 141 份表、ANNiKEY、Nereididae DELTA，Zenodo 10.5281/zenodo.7776745）尚未下载。
- 分级：L1 仅表文本（A1 A2 A3 A6 + 反推矩阵）；L2 矩阵（A4 A5 A7 及重编译）；L3 标本与分子真值（后做）。表 vs taxadb 描述比对在 L2 之后。

## 6. 里程碑与验收（Codex #21、#23）
通用：ruff --line-length 120、mypy、pytest 全过；不改 booklayout/。
- M1 matrix.py + 导入 + 校验。验收：给定规范化矩阵与预期错误码表（E01–E07、W01–W02、I01），每个错误码至少一个触发用例；非法父链、无效状态、错误继承不得通过；上卷测试：直接上卷与逐级上卷相等、折叠单型层前后相等；G={00,11}/H={01,10} 反例中两属可分。
- M2 build.py。验收：写一个**独立的暴力枚举器**（对小矩阵枚举全部可能观测，算出每个观测应到达的终点集合），断言：应到者全到、不应到者均不到、已知可分者必须唯一；"全部 unresolved"的空实现必须失败。另测：零种、单种、必须共享终点、输入行列重排结果一致、四种多态情形（全在一侧/横跨两侧/未知/已知不适用）、区间 A/B/C 回归、su 手算值。
- M3 hier.py。验收：科-属-种玩具矩阵上，linked 与 hybrid 都能从每个底层观测走到唯一预期目标；"属内两种仅靠红/蓝区分、父表已问红或蓝"的用例必须能在子表继续问颜色；两入口子表按入口回放。
- M4 audit L1。验收：冻结正负样例与留出集，精确到规则、对句、种对；每条规则比对预期与实际证据集合（命中一半不算命中）；无缺陷的对照表零报警。
- M5 audit L2 + CLI（python3 -m keykit {matrix-build|hier|audit}）+ 排版导出。验收：逐项覆盖 A4 A5 A7 A8（A8 用固定快照）；每个子命令定义输入、退出码、结构化输出及失败样例；导出 docx/pdf 后逐项核对编号、跨表目标、终点集合。
