# 任务清单
- [ ] PLAN:20 多态/未知两支都走：已知只有红蓝的种会被送进错误分支。INAPPLICABLE 也被允许继续问。要先求剩余状态域与两侧谓词的交集。
- [ ] PLAN:12,29 逐列上卷取并会凭空造出性状组合。反例：属 G 为 00、11，属 H 为 01、10，上卷后全部变成 {0,1}×{0,1}，可分的属被判成不可分。要沿路径保留联合约束。
- [ ] PLAN:30,52 linked 模式的“已问性状不重问”会禁止必要的细分，造成假 unresolved。要透传剩余值域，只禁止已被穷尽的问题。
- [ ] PLAN:39 A4 把“无可比性状（全 UNKNOWN）”和“比较后无差异”记成同一个零，会误报同物异名。
- [ ] PLAN:17,42 A7 的两个触发条件推不出矩阵本身分不开。反例：16 个种各有一个专属性状，都能唯一鉴定，但等权平均要 8.4375 步，而自由平衡树只要 4 步。
